# Демо «Живой штрих» (EditorDemo)

Одно окно с документом-образцом, где можно сразу проверить перо в тексте: подчёркивания, обводки, заметки на полях, блок рисования, ластики, лассо, поворот и смену ширины колонки. Bundle ID — `com.datascratch.app.editordemo`, iPad и iPhone, iOS 26+.

## Как поставить на iPad (Mac с Xcode)

```bash
brew install xcodegen                     # один раз
cd apps/ios/Packages/DSEditor/Demo
xcodegen generate                         # создаст EditorDemo.xcodeproj
open EditorDemo.xcodeproj
```

В Xcode: цель **EditorDemo** → Signing & Capabilities → выбрать свою команду (Team). Подключить iPad кабелем (или по сети), выбрать его вверху и нажать ▶︎.

## Без Mac (временный вариант)

Каждая сборка CI (`ios-editor.yml`) выкладывает артефакт `EditorDemo-unsigned-ipa`. Его можно подписать своим Apple ID и поставить через Sideloadly или AltStore (Windows/Mac). Подпись бесплатного Apple ID действует 7 дней.

## Что проверить

1. Выбрать ручку (палитра снизу), подчеркнуть фразу, которая переносится на две строки; повернуть iPad — подчёркивание режется на две части и остаётся на словах.
2. Вставить слово перед подчёркнутым — штрих едет вместе с текстом. Нажать Enter внутри подчёркнутой фразы — штрих тоже разделится.
3. Удалить помеченное слово — пометка исчезает; «Отменить» возвращает и слово, и пометку (D-35).
4. Меню «Аа» → ширина колонки «Обычная / Широкая / Во всю ширину»; Split View / Stage Manager — то же самое.
5. Сжать Pencil Pro — откроется палитра; двойное касание — ластик (по системной настройке).
6. Зигзаг по слову и задержать перо — слово удалится; линия под словом с задержкой — подчёркивание текстом.
7. Нарисовать на полях слева/справа от колонки — заметка на полях, едет вместе с абзацем.
8. Меню «…» → «Замеры»: время открытия, перерисовка пера, кадры в секунду; «Открыть 10 000 слов» — проверка скорости открытия.
9. «…» → «Сохранить», закрыть приложение, открыть снова — всё на месте (документ сохраняется и при уходе в фон).
