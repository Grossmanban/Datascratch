## 2026-10-25 (вторая половина дня)

- 2026-10-27 · core · `rate_limited` по частоте: клиент не рвёт соединение, а приостанавливает отправку до `retryAfterMs` и повторяет неподтверждённое; лимит снимка 16 MiB (`MAX_SNAPSHOT_BYTES`, sync-protocol §7); в контракте — лимиты соединений и коды закрытия сервера.
- DSCore, аудит безопасности 2026-10-27: параметры KDF из `prelogin` проверяются по границам crypto.md §2 (`CryptoError.unsafeKDF`); id вложений — только UUIDv7 во всех операциях с файлами и в обложке (никакого `../` за пределы папки вложений); id в путях REST — только простые сегменты (`UnsafePathError`); `download` сверяет описание вложения с сервера (куски, размер, лимит 200 МБ) и пишет на диск по кускам; `AttachmentManager.wipeLocal` для «Удалить данные с этого устройства».
- **agents (аудит безопасности):** экран согласия больше не даёт выдать себя за известного агента: главное «лицо» клиента — проверенный хост `client_id` (документ метаданных) или, для динамически зарегистрированных клиентов, адрес возврата («программа на этом компьютере», «приложение cursor», сайт) с пометкой «не проверен»; название показывается как «называет себя «…»»; у непроверенных клиентов нет логотипа (и пикселя слежения) и ссылки на сайт, есть предупреждение.
- **agents (аудит безопасности):** регистрация OAuth-клиентов ограничена: не больше 10 `redirect_uris` по 2000 символов, `client_uri`/`logo_uri` — только https; документ метаданных клиента читается потоком и обрывается на 64 КиБ; страница `/oauth/authorize` ограничена по частоте с одного адреса; сервер раз в час удаляет клиентов старше суток без единого разрешения.
- **agents (аудит безопасности):** ошибки запроса авторизации до экрана согласия больше не перенаправляются на адрес клиента — показывается страница ошибки (иначе сервер был бы открытым редиректором, RFC 9700 §4.11.2); собственные схемы приложений в `redirect_uris` — только обратные доменные имена (`com.example.app:`, RFC 8252 §7.1) и известные приложения (`cursor`, `vscode`, `windsurf`, `zed`, `claude`); ротация refresh-токена атомарна (`UPDATE … RETURNING`), а повторное предъявление уже использованного токена отзывает всё подключение.
- **agents (аудит безопасности):** картинки рукописи ограничены: кадр не больше 1600×2400 pt вокруг штрихов (заметка на полях огромного блока, далёкие точки, огромная `height` рисунка), холст не больше 16 Мпикс (масштаб снижается сам), раскладывается не больше 20 000 символов блока, рисуется не больше 300 000 точек; картинки больше 40 Мпикс не декодируются (размер читается из заголовка PNG/JPEG) — рисуется заглушка.
- **agents (аудит безопасности):** чтение и импорт текста больше не могут подвесить сервер: экспорт в Markdown линейный (раньше «a» + 200 тыс. пробелов + «b» занимало ~17 с), ограничены повторения в поиске `[[…]]`/`==…==`/`[^…]` и сущностей `&…;`, даты задач ищутся только в конце строки; узлы заметки вставляются в Yjs одним вызовом (тысячи тегов, переносов, строк таблицы — без квадратичной вставки); слишком длинные абзацы (разбор micromark квадратичен внутри абзаца) отклоняются с понятной ошибкой; вложенность Markdown — не глубже 50; ссылки `javascript:`, `data:`, `vbscript:`, `file:` при импорте теряют ссылку, текст остаётся.
- **server (аудит безопасности):** расшифрованные ключи заметок блокнотов «для агентов» хранятся в памяти не дольше 10 минут и сбрасываются сразу при выключении режима «для агентов», удалении блокнота, отзыве или сужении разрешения агента.
