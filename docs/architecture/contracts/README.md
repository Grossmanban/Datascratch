# Контракты между частями системы

> Статус: **ПРЕДЛОЖЕНО (v1, 2026-10-25)** — технические детали, утверждённые координатором для параллельной разработки (D-39). Пользователь их не обязан утверждать, но любое изменение — только через сессию-координатора: контракт ломает совместимость iOS ↔ веб ↔ сервер.

Контракт — это точное описание формата или протокола, который реализуют **несколько** частей системы. Каждая часть (iOS на Swift, веб и сервер на TypeScript) реализует его сама; совместимость доказывается **общими тестовыми векторами** (`packages/test-vectors`, D-22).

| Контракт | Что описывает | Кто реализует |
| --- | --- | --- |
| `document-model.md` | Структура документа Yjs: блоки, атрибуты, метаданные, индексы блокнота и аккаунта | iOS-редактор, iOS-приложение, веб, сервер (агенты) |
| `strokes.md` | Формат рукописного штриха и якорей | iOS-редактор, веб, сервер (рендер PNG) |
| `sync-protocol.md` | Протокол синхронизации по WebSocket | Сервер, iOS, веб |
| `crypto.md` | Ключи, вывод ключей из пароля, формат шифротекста | iOS, веб, сервер (режим «для агентов») |
| `api.md` | REST API сервера | Сервер, iOS, веб |
| `design-tokens.md` | Дизайн-токены «Тихая бумага» | iOS, веб |

## Правила изменения

1. Контракт версионируется: `v1`, `v2`… Изменение, ломающее совместимость, — новая версия с явной миграцией.
2. Сессия-исполнитель, которой нужно изменить контракт, **не меняет его сама**, а пишет координатору (сессия, указанная в задании) с предложением.
3. Координатор обновляет контракт, тестовые векторы и сообщает всем затронутым сессиям.
4. Типы TypeScript, отражающие контракты, лежат в `packages/shared/src/contracts/` — они часть контракта.
