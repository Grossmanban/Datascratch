# Контракт: рукописные штрихи (v1)

> Уточнение 2026-10-25 (предложения потока core): изменяемые поля `anchors`/`hidden`, перепривязка якорей после отмены и восстановления версии (§4.1), момент «осиротения» штриха (§4.2).

Связано: D-05 (живой штрих), D-35 (штрих на удалённом тексте), D-11 (PNG для агентов). Типы TS: `packages/shared/src/contracts/strokes.ts`. Кодек TS: `packages/shared/src/strokes/`.

## 1. Где хранятся

В документе заметки: `Y.Map "strokes"`, ключ — `strokeId` (UUIDv7), значение — `Y.Map` со полями ниже. Штрих — почти неизменяемый объект: после завершения рисования меняются только `anchors` (перепривязка, §4.1) и `hidden` (резерв). Ластик **удаляет** штрих целиком (ластик по штриху) или заменяет его новыми штрихами-кусками (ластик по пикселю).

## 2. Поля штриха

| Поле | Тип | Смысл |
| --- | --- | --- |
| `v` | number | версия формата штриха = `1` |
| `tool` | `"pen"\|"pencil"\|"marker"\|"highlighter"` | инструмент |
| `color` | string | токен цвета чернил (`ink.black`, `ink.blue`, …) или `#RRGGBB` |
| `width` | number | базовая толщина в pt при нажиме 1.0 и размере шрифта 17 pt (масштабируется вместе с текстом) |
| `opacity` | number | 0..1 |
| `anchorKind` | `"text"\|"block"\|"image"\|"drawing"` | к чему привязан |
| `blockId` | string \| null | для `block` (заметка на полях абзаца), `image`, `drawing` |
| `anchors` | `Uint8Array[]` | только для `text`: закодированные относительные позиции Yjs (`Y.encodeRelativePosition`) внутри `content`, по одной на символ, которого касается штрих |
| `points` | `Uint8Array` | упакованные точки (раздел 3) |
| `hint` | `"free"\|"underline"\|"strike"\|"circle"\|"highlight"\|"arrow"\|"scribble"` | распознанная форма (для агентов и экспорта) |
| `author` | `{ kind: "user"\|"guest"\|"agent", id: string }` | |
| `createdAt` | number | Unix ms |

## 3. Упаковка точек

`points` — последовательность записей по **8 значений Float32 little-endian (32 байта)**:

```
[ a, x, y, pressure, altitude, azimuth, roll, t ]
```

| Значение | Для `text` | Для `block` / `image` / `drawing` |
| --- | --- | --- |
| `a` | индекс якоря в `anchors` (целое, как float) | `-1` |
| `x`, `y` | смещение от **начала глифа** якорного символа (передний край по x, базовая линия по y) в **em** — единицах размера шрифта этого символа; y растёт вниз | координаты в долях **ширины** блока/картинки: x ∈ 0..1, y ≥ 0 (в тех же единицах ширины); для `block` (заметки на полях): x — от левого края колонки текста в долях ширины колонки (может быть < 0 и > 1 — штрих левее или правее абзаца), y — от верха абзаца в тех же единицах |
| `pressure` | 0..1 (нажим; без поддержки — 1) | то же |
| `altitude` | радианы, 0..π/2 (наклон; без поддержки — π/2) | то же |
| `azimuth` | радианы, 0..2π | то же |
| `roll` | радианы (вращение Pencil Pro; без поддержки — 0) | то же |
| `t` | мс от начала штриха | то же |

Записывается только завершённый штрих: «сглаженные» точки после coalesced-обработки, без predicted-точек.

## 4. Привязка к тексту (живой штрих)

При рисовании поверх текста клиент для каждой точки находит ближайший символ строки, над/под которой лежит точка (по вертикали — строка, в чьих границах лежит точка; если ни в одной — ближайшая), и сохраняет:

- относительную позицию этого символа (добавляет в `anchors`, если её там ещё нет),
- смещение точки от начала глифа символа в em.

Точка ровно на границе двух символов привязывается к **правому** символу (уточнение потоков ios-editor и web-editor, 2026-10-25); в конце строки, где правого символа нет, — к последнему символу строки.

При отрисовке (после любой перекладки):

1. Каждый якорь превращается в абсолютную позицию (`createAbsolutePositionFromRelativePosition`, с учётом redone-элементов) и затем в текущий прямоугольник глифа.
2. Точка = начало глифа + (x, y) × размер шрифта символа.
3. **Разрыв по строкам:** если две соседние точки привязаны к символам на разных строках (разных line fragments), штрих в этом месте разрывается — рисуется несколько независимых сегментов.
4. **Удалённый текст (D-35):** относительная позиция удалённого символа резолвится Yjs в соседнюю позицию, а не в «пусто» — поэтому признак «символ удалён» проверяется по самому элементу Yjs (с учётом redone), а не по результату резолвинга. Точки, чей якорный символ удалён, не рисуются; сегмент короче 2 точек не рисуется; штрих, у которого удалены все якоря, не рисуется вовсе. Сам штрих при этом из документа **не удаляется** — отмена удаления текста возвращает и пометку (с перепривязкой якорей, §4.1). Окончательное удаление — §4.2.

**Штрих вдали от текста (свободный рисунок).** Привязка к символу имеет смысл только рядом с текстом. Если хотя бы одна точка штриха лежит дальше **3 em** (по вертикали) от ближайшей строки с символами — например, рисунок ниже конца заметки, на пустом месте между абзацами или крупный набросок поверх нескольких абзацев, — **весь** штрих сохраняется как свободный рисунок: `anchorKind: "block"` у ближайшего по вертикали абзаца (ниже последнего абзаца — у последнего; в пустой заметке — у единственного), координаты как у заметок на полях (§3: x от левого края колонки в долях её ширины, y от верха абзаца в тех же единицах, y может быть сколь угодно большим). Такой рисунок едет вместе со своим абзацем, но не растягивается по буквам. Отбрасывать точки или весь штрих из-за отсутствия близкого символа **нельзя** — нарисованное пером не должно пропадать. Редактор держит под последним абзацем свободное место для рисования (не меньше высоты видимой области) и включает в высоту содержимого все свободные рисунки, чтобы до них можно было докрутить. (Решение координатора 2026-10-25 по отзыву пользователя «рисую далеко от текста — при отпускании пропадает»; ПРЕДЛОЖЕНО.)

Обводки вокруг нескольких слов и стрелки между строками подчиняются тем же правилам: каждая точка привязана к ближайшему символу, поэтому обводка «растягивается» вместе с текстом. Если такое поведение окажется плохим на практике, это решается в потоке iOS-редактора и меняет контракт через координатора.

### 4.1. Перепривязка якорей (отмена и восстановление версии)

Ссылка «redone» у элементов Yjs локальна: в обновления она не попадает и не переживает перезагрузку. Поэтому на других устройствах текст, возвращённый отменой, — это **новые** элементы, и старые якоря указывают на удалённые символы. Правило:

- Клиент, выполнивший **отмену/повтор**, в той же транзакции перепривязывает затронутые штрихи: для каждого якоря, чей символ удалён, но имеет redone-элемент, записывает в `anchors` относительную позицию нового элемента (хелпер TS `rebaseRedoneAnchors(doc)`; на iOS — эквивалент в DSCore). Остальные устройства получают уже исправленные `anchors` обычной синхронизацией.
- При **восстановлении версии из истории** клиент восстанавливает и `content`, и `strokes` версии; якоря пересчитываются через абсолютные индексы: позиция якоря в старой версии → тот же индекс в восстановленном тексте → новая относительная позиция.

### 4.1a. Перестройка блоков (разделение, слияние, смена типа, перемещение)

y-prosemirror при разделении абзаца (Enter в середине), слиянии (Backspace в начале), смене типа блока и перемещении блока **пересоздаёт** перенесённый текст новыми элементами Yjs — старые якоря указывают на удалённые символы, и пометка пропала бы по D-35. Правило: клиент, выполняющий такую операцию, в **той же транзакции** заменяет каждый затронутый штрих копией с новыми якорями (новый `strokeId`, те же точки, якоря пересчитаны по соответствию символов до/после операции). Отмена операции возвращает исходный штрих. (Предложение потока ios-editor, 2026-10-25; касается и веба.)

В вебе транзакцию перестройки выполняет y-prosemirror, поэтому копия штриха записывается **сразу после** неё отдельной транзакцией с отслеживаемым origin — `Y.UndoManager` объединяет обе в один шаг отмены. Это эквивалентно правилу выше. Хелперы TS: `captureAnchorOffsets` → `reanchorStrokes` (`@datascratch/shared/strokes`).

### 4.2. Когда штрих считается «осиротевшим» и удаляется навсегда

Yjs не хранит момент удаления текста. Клиент локально запоминает `orphanedAt` — когда впервые увидел, что все якоря штриха удалены (и стирает отметку, если якоря снова живы). При уплотнении истории клиент, собирающий снимок, удаляет штрихи, у которых все якоря удалены и `orphanedAt` (если неизвестен — `createdAt`) старше 30 дней.

## 5. Отрисовка толщины

Толщина в точке = `width × f(pressure) × (fontSize/17)` для `text` и `width × f(pressure) × (blockWidth/600)` для остальных. `f(p) = 0.35 + 0.65 · p^0.8` (общая кривая для всех платформ, чтобы штрих выглядел одинаково). Наклон влияет только у `pencil` и `marker` (ширина × (1 + 1.5 · (1 − altitude/(π/2)))). Маркер (`highlighter`) рисуется под текстом с режимом наложения multiply.
