- **server:** `PATCH /v1/notebooks/:id/mode` с `mode=agent` отклоняет (409 «key mismatch») ключ блокнота, который не расшифровывает ни одного из последних элементов документа блокнота, вместо того чтобы молча заменить серверную копию; в лог пишется смена серверной копии ключа (отпечатки старого и нового) и документы с элементами под разными ключами.
