- **agents:** общие блокноты для своего ИИ участника (D-54, поправка 2026-10-28): блокнот, которым поделились и который владелец открыл агентам, виден агенту участника с его ролью — редактор читает и правит, читатель только читает (правки → понятная ошибка «только чтение»); `list_notebooks` помечает такие блокноты `shared: { ownerEmail, role }`, `list_spaces` собирает их в «Общие со мной», экран согласия подписывает «общий · почта владельца · только чтение»; `move_note` — только между блокнотами одного владельца.
