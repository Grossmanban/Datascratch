- DSCore: тесты больше не падают по времени на загруженном CI — ожидание `eventually` считает время, когда проверка реально могла выполняться (при голодании пула часы стоят, зависание всё равно ловится), тест снимка ждёт явных условий (последний seq у сервера и у второго устройства). `SyncEngine` быстрее разбирает очередь из сотен правок: окно отправки пополняется пачками, статус не пересчитывается на каждое подтверждение (500 правок: 2–5 с → 1,1–1,9 с).
