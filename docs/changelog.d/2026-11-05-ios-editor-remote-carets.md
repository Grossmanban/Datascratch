- iOS, редактор: каретки соавторов в тексте — тонкая линия в цвете человека с именем (гаснет через 3 с без движения), подкрашенное выделение, метка у верхнего или нижнего края для каретки за экраном (касание прокручивает к ней). Данные — awareness веба (`cursor.anchor/head`, относительные позиции Yjs), API `EditorView.setRemoteCursors([RemoteCursor])`; имя и цвет очищаются как на вебе, свои устройства (`user.account`) не показываются.
