- 2026-11-08 — сервер, D-65: голос через сервер — `POST /v1/voice/transcribe` (запись до 200 МБ и 3 ч потоком в ElevenLabs Scribe, без записи на диск; реплики по говорящим S1, S2…) и `POST /v1/voice/text` (чистовик, итог разговора или «Оформить» через OpenRouter по подсказкам из `@datascratch/shared/voice`, обычная или лучшая модель, без провайдеров, хранящих данные). Ключи — только на сервере (секреты GitHub → `.env` при выкладке, не в журнал). Кому включён голос, решает администратор сервера (`DS_ADMIN_EMAILS`) в приложении: `GET/PUT /v1/admin/voice` — аккаунты, минуты, расход и стоимость за месяц; `GET /v1/voice/me` — включён ли и сколько осталось; изменение сразу приходит устройствам (`account_changed` `voice`). Минуты в месяц: 600 у администратора, 120 у остальных; лимит частоты. Аудио и тексты не хранятся и не попадают в журнал — только размеры, длительности, модель, стоимость и код (проверено тестом). Миграция 0012; Caddy и nginx пропускают 200 МБ только на этот путь; `ds voice` на сервере. Исходящий прокси только для голоса — `DS_VOICE_PROXY` (сервер в России; TLS сквозной, прокси не видит содержимого).
