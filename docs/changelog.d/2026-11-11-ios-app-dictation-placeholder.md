- iOS, голос: записанный кусок стоит в тексте там, где его сказали, — заглушка «Распознаю… 0:42», затем распознанный текст на её месте (одним шагом отмены), даже если курсор ушёл. Нераспознанная запись — «Запись не распознана» в тексте, по нажатию — «Повторить» / «Сохранить аудио» / «Удалить»; после повторного открытия заметки заглушки на своих местах. Тесты: модульный (заглушка, ошибка, замена), UI — нажатие на заглушку → «Повторить» → текст на её месте; стабилизированы два UI-теста оформления и тест «Стоп» в режиме без рук.
