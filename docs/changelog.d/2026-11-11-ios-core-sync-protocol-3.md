- DSCore, протокол синхронизации 3: после переподключения телефон спрашивает у сервера, что изменилось с прошлого раза (`resume` по курсору аккаунта), и подписывает только это — а не всю библиотеку. Курсор сохраняется, только когда всё догнано; без ответа сервера за 20 с всё подписывается, как раньше. Большая правка (до 16 МиБ) — обычное обновление; старому серверу она уходит снимком, и устройства в сети получают её сразу.
