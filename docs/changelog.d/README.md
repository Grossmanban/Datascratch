# Фрагменты журнала изменений

Сессии-исполнители (D-39) не правят `docs/CHANGELOG.md` напрямую, чтобы не было конфликтов при слиянии. Каждая пишет фрагмент `ГГГГ-ММ-ДД-<поток>-<кратко>.md` (одна-три строки в формате журнала). Координатор при слиянии в `main` переносит фрагменты в `CHANGELOG.md` и удаляет их.
