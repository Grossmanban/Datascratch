- iOS (D-54, сборка 23): совместный доступ по аккаунтам. «Поделиться» у блокнота и заметки — по почте, роли «Может редактировать» / «Только чтение», список людей со сменой роли и удалением, ждущие приглашения (отозвать, скопировать ссылку). Приглашения с бейджем и «Принять» / «Отклонить», раздел «Общие со мной» в боковой панели каждого пространства, «Выйти». Владелец подтверждает доступ для зарегистрировавшихся после приглашения («… зарегистрировалась — открыть доступ?»); после удаления участника ключ меняется, гостевые ссылки создаются заново и показываются («Ссылки обновлены»). «Только чтение»: полоса над заметкой, без клавиатуры, пера и панелей. История версий: кто менял, сравнение с предыдущей версией (добавленное подсвечено, удалённое зачёркнуто), восстановление для тех, кто может править. Режим «для агентов» у общего блокнота меняет только владелец.
- iOS (сборка 23): `DS_SERVER_URL` удалён из сборки полностью (project.yml, xcconfig, ios-release.yml) вместе с однократной миграцией сборки 22 — в приложении нет ни одного адреса сервера.
- iOS (сборка 23): релизная сборка больше не печатает домен в публичных логах — `DS_WEB_HOST` берётся из секрета только в шаге архивации и сразу маскируется; без секрета сборка проходит с `datascratch.app`. Приложение больше не читает домен из Info.plist — ссылки строятся от адреса сервера аккаунта.
