- iOS: библиотека устройства, в которой только нетронутое стартовое содержимое (пространства «Личное»/«Работа», блокнот «Заметки», приветственная заметка, пустой Inbox), больше не переносится в аккаунт при входе (D-43) — иначе в аккаунте появлялись вторые «Personal»/«Work». Стартовые пространства и блокноты на английском и русском («Personal» = «Личное», «Work» = «Работа», «Notes» = «Заметки») считаются одними при слиянии дублей — уже появившиеся двойники сольются при следующем запуске.
