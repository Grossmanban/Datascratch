- iOS: по умолчанию — только заметки (D-51). Экран «Задачи», «Календарь», «Заметка на сегодня», вкладки (раздел в боковой панели, «Закрыть вкладку», восстановление активной вкладки) и меню переноса дат задач скрыты; ⌘W закрывает документ. Включаются флагом сборки `DS_EXTENDED_MODE = YES` (Info.plist `DSExtendedMode`) или аргументом запуска `-ds-extended-mode YES`. Данные не меняются: даты задач и вкладки в документе аккаунта остаются как есть, приложение в обычном режиме их не пишет.
