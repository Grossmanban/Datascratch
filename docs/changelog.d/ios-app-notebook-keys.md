- iOS: ключи блокнотов — приложение больше никогда не создаёт ключ для уже существующего блокнота (раньше заметка в блокноте, ключа которого на устройстве не было, порождала новый ключ, неизвестный серверу, и блокнот шифровался им). При каждом старте синхронизации ключи сверяются с сервером (`GET /notebooks`): недостающие загружаются, придуманный ключ заменяется серверным, ключи заметок перешифровываются, состояние блокнота отправляется заново. Ключи блокнотов, созданных на других устройствах, подгружаются, как только они появляются в аккаунте.
