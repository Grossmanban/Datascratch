- iOS: ключи блокнотов (прод-инцидент «Ии») на примитивах DSCore — приложение никогда не создаёт ключ для существующего блокнота; на каждом старте синхронизации и при появлении блокнота без ключа — `reconcileNotebookKeys` (недостающие ключи загружаются, придуманный заменяется серверным, старый остаётся «отставным» только для чтения), `rewrapNoteKeys`, `SyncEngine.rekey` (перечитать с нуля и выложить канонический снимок), `retryUnreadable`; после успешного `POST /notebooks` ключ отмечается подтверждённым, 409 — сверка ключей. Заметки, чей ключ открывал только утерянный придуманный ключ, но содержимое есть на устройстве, получают новый ключ и выкладываются заново; однократно (build 12) все блокноты перечитываются и выкладываются заново. Режим «для агентов» передаёт серверу только подтверждённый серверный ключ. Блокнот без ключа — «только чтение» («Блокнот готовится»); блокнот с нечитаемыми изменениями — спокойная плашка «Часть изменений здесь пока не читается».
