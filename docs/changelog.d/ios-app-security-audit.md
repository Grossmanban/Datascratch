- iOS (аудит безопасности): имена и идентификаторы из заметок больше не могут стать путями к файлам; удаление данных с устройства стирает и расшифрованные вложения и закрывает сессию на сервере; ключ восстановления, токен агента и ссылки с ключом копируются только на это устройство и исчезают из буфера через минуту; ключ в настройках показывается после Face ID и скрыт при записи экрана; огромные изображения не роняют приложение (уменьшаются из файла, больше 50 Мп — отказ); картинки из вставленных страниц скачиваются только по https с ограничениями и не с адресов локальной сети.
- iOS: исправления ios-core подключены — небезопасные параметры KDF от сервера («Сервер прислал небезопасные параметры входа») при входе, смене пароля, восстановлении и смене ключа; неверные пути и загрузки вложений — понятная ошибка или «не загружено», без падения; стирание вложений через `AttachmentManager.wipeLocal`.
