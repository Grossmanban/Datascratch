- iOS: боковая панель для большого числа блокнотов и тегов (§12.6): «Избранное», «Блокноты» и «Теги» сворачиваются по заголовку (запоминается на устройстве для каждого пространства); в разделе видно до 7 строк, остальные — строкой «Ещё N», в конце — «Свернуть»; открытый блокнот виден всегда; теги — деревом по `/`, первые — по недавнему использованию; «Все теги» — лист с поиском, цветом и счётчиками; блокноты можно переставлять перетаскиванием.
