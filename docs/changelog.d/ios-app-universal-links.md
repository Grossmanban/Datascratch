- iOS (сборка 24, D-56): ссылки `ds://` из веба открываются в приложении, и при запуске с них. Приглашение — карточка «Принять» / «Отклонить». Гостевая ссылка — гостевая страница своего сервера внутри приложения. Документ и блокнот открываются. Если сервер в ссылке не тот, где вход, — понятное сообщение с выходом в браузер. Без входа поле «Сервер» заполняется из ссылки. Universal Links, Associated Domains и `DS_WEB_HOST` убраны: в сборке нет ни одного домена.
