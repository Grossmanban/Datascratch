# D-01. Хранение заметок — в базе данных на своём сервере, не в файлах

- **Статус:** РЕШЕНО
- **Дата:** 2026-10-25 (зафиксировано из обсуждения в claude.ai)
- **Связано:** `docs/spec/06-data-server.md`, `docs/spec/04-editor.md`

## Контекст

Пользователя не устраивает Obsidian: всё лежит в файлах, это слишком нагружено для нормальной синхронизации через Apple. Нужен свой сервер («храни как надо»).

## Решение

Свой сервер. Заметки хранятся в базе данных как структурированные документы (CRDT), а не файлами. Markdown — только формат экспорта и формат выдачи агентам.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
| --- | --- | --- |
| Файлы Markdown (как Obsidian) | Переносимость, читаемо без приложения | Тяжёлая синхронизация, конфликты, невозможно хранить рукопись с привязкой к тексту |
| **База + CRDT** | Надёжная синхронизация, совместная правка, рукопись в той же структуре | Нужен экспорт, чтобы данные не были «заперты» |

## Последствия

Обязателен качественный экспорт в Markdown/PDF/HTML. Рукопись привязывается к структуре документа, а не к файлу.
