# D-02. Отдельной десктоп-версии нет, на компьютере — веб

- **Статус:** РЕШЕНО
- **Дата:** 2026-10-25 (зафиксировано из обсуждения в claude.ai)
- **Связано:** D-03, `docs/spec/02-platforms.md`

## Решение

Нативных приложений для macOS/Windows/Linux не делаем. На компьютере используется полноценный веб-клиент (устанавливается как PWA).

## Последствия

Веб должен быть полным, без урезаний (D-03). Экономит целую платформу в разработке.
