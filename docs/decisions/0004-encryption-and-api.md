# D-04. Одновременно сквозное шифрование и доступ по API

- **Статус:** РЕШЕНО
- **Дата:** 2026-10-25 (зафиксировано из обсуждения в claude.ai)
- **Связано:** D-09, D-10, D-11, `docs/spec/07-encryption.md`, `docs/spec/09-agents-api.md`

## Контекст

Нужно и сквозное шифрование (как Notesnook), и доступ внешних ИИ-агентов к заметкам. Эти требования противоречат друг другу: агент на сервере не может читать то, что сервер не может расшифровать.

## Решение

Два режима блокнотов:
- **Приватный** — сквозное шифрование, ключ только на устройствах, агентам недоступен.
- **Для агентов** — ключ блокнота в защищённом хранилище на сервере, расшифровка только по запросу с действительным токеном и правами.

## Последствия

Пользователь сам решает, чем жертвует для каждого блокнота. В интерфейсе честно предупреждаем, что во втором режиме сервер технически может прочитать заметки. На будущее — локальный MCP-мост для доступа агентов к приватным блокнотам без передачи ключа серверу.
