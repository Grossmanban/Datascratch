# D-07. Распознавание рукописи в текст — не делаем

- **Статус:** РЕШЕНО
- **Дата:** 2026-10-25 (зафиксировано из обсуждения в claude.ai)
- **Связано:** `docs/spec/03-pencil.md`

## Решение

Не распознаём уже нарисованную рукопись в текст. Системный Scribble (рукописный ввод в текстовые поля средствами iOS) работает сам и поддерживается.
