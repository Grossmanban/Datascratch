# D-09. Режим блокнота выбирается при создании, сменить можно позже

- **Статус:** РЕШЕНО
- **Дата:** 2026-10-25 (зафиксировано из обсуждения в claude.ai)
- **Связано:** D-04, `docs/spec/07-encryption.md`

## Решение

При создании блокнота пользователь выбирает режим: приватный или для агентов. Сменить можно в любой момент — клиент перешифровывает данные.
