# D-10. Правки агента применяются сразу, подсвечиваются, откатываются через историю

- **Статус:** РЕШЕНО
- **Дата:** 2026-10-25 (зафиксировано из обсуждения в claude.ai)
- **Связано:** `docs/spec/09-agents-api.md`, `docs/spec/10-sync.md`; уточнено D-45 (заметки, созданные агентом)

## Решение

Правки агента не ждут подтверждения — применяются сразу. В интерфейсе они подсвечиваются; откат — через историю версий. Рукописные якоря при этом не ломаются (они — относительные позиции CRDT).

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
| --- | --- | --- |
| **Сразу + подсветка + откат** | Быстро, агент работает автономно | Нужна хорошая история версий |
| Предложения на подтверждение | Полный контроль | Трение, агент «ждёт» человека |
