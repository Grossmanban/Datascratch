# D-11. Рукопись для агента — рендер в картинку (PNG)

- **Статус:** идея — РЕШЕНО; формат PNG — ПРЕДЛОЖЕНО
- **Дата:** 2026-10-25
- **Связано:** `docs/spec/09-agents-api.md`

## Решение

Рукописные фрагменты рендерятся сервером в картинки, чтобы агент «видел» их, плюс текстовая пометка, к чему фрагмент привязан («подчёркнуто от руки: …»). Формат — PNG: модели со зрением читают PNG хорошо, а SVG из тысяч координат — плохо. SVG — опционально для экспорта. Только для блокнотов «для агентов».
