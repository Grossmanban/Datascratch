# D-13. Совместная работа: шеринг по ссылке, правка без аккаунта, реальное время

- **Статус:** РЕШЕНО
- **Дата:** 2026-10-25 (зафиксировано из обсуждения в claude.ai)
- **Связано:** `docs/spec/08-sharing.md`

## Решение

Шеринг по ссылке с правкой даже без аккаунта, редактирование в браузере на iPhone и iPad; если установлено приложение — ссылка открывается в нём. Совместная правка в реальном времени. Ключ шифрования — в части ссылки после `#` (не уходит на сервер).

## Последствия

Требует CRDT (D-31) и Universal Links (платный аккаунт Apple Developer).
