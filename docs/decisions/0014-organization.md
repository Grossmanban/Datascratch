# D-14. Организация: богатая, но не перегруженная

- **Статус:** РЕШЕНО (требование); конкретная структура — ПРЕДЛОЖЕНО
- **Дата:** 2026-10-25
- **Связано:** `docs/spec/05-organization-design.md`

## Решение

Проекты, личное, работа, учёба не смешиваются; папки и вложенные папки, умные теги, цвета. Минимум кнопок на экране.

Предложенная структура: пространства → папки с вложенностью; поперёк — вложенные и умные теги, цвета и иконки, избранное и недавние.
