- **Дата:** 2026-10-25 (зафиксировано из обсуждения в claude.ai)

## Решение

Максимально красивый интерфейс, ощущение премиального SaaS-продукта, а не «программы энтузиаста». Ориентиры: Things 3, Linear, Craft, Arc.

## Последствия

Компромиссы по красоте и плавности не принимаются молча — только через обсуждение с пользователем. Собственная дизайн-система, единая для iOS и веба.
