# D-18. Монетизация — не решена; архитектура готова к self-hosting

- **Статус:** монетизация — ОТКРЫТО; готовность к self-hosting — ПРЕДЛОЖЕНО (фактически реализуется: D-25, D-26)
- **Дата:** 2026-10-25
- **Связано:** D-12, D-25, D-26, D-30

## Контекст

Варианты: подписка; разовая покупка; open source с self-hosting + платный хостинг «для ленивых».

## Решение (на сейчас)

Монетизация не выбрана. Архитектура с первого дня поднимается одной командой Docker, чтобы не закрывать вариант с self-hosting. Выбор PostgreSQL (D-30) сделан в том числе с расчётом на возможный платный хостинг для многих пользователей.
