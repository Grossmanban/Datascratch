# D-22. Без собственного общего ядра на Rust

- **Статус:** РЕШЕНО (подтверждено пользователем 2026-10-25)
- **Дата:** 2026-10-25
- **Связано:** D-21, D-27, D-31

## Контекст

В черновике ТЗ (claude.ai) было общее ядро на Rust для iOS и веба (логика документа, шифрование, синхронизация).

## Решение

Своё ядро на Rust не пишем. Вместо него — экосистема Yjs/Yrs (готовые совместимые реализации), libsodium на обеих сторонах и общие тестовые векторы (`packages/test-vectors`), прогоняемые и в Swift, и в TypeScript.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
| --- | --- | --- |
| Общее ядро на Rust (FFI в iOS, WASM в вебе) | Одна реализация логики | Третий язык, сложная сборка под iOS и WASM, сложнее отладка |
| **Готовые совместимые библиотеки + тестовые векторы** | Два языка, проверенные библиотеки | Логику, которой нет в библиотеках, пишем дважды — страхуемся векторами |

## Последствия

Yrs написан на Rust, но это готовая библиотека, а не наш код на Rust — решение от этого не меняется.
