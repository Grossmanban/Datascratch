# D-23. Документация — источник истины; Graphify — граф знаний поверх неё

- **Статус:** РЕШЕНО (требование пользователя; структура `docs/` утверждена 2026-10-25)
- **Дата:** 2026-10-25
- **Связано:** D-19, D-29, `docs/README.md`, `CLAUDE.md`

## Контекст

Требование пользователя: в любой момент передать репозиторий другому ИИ, который впервые его видит, — и он должен понять всё идеально, без чатов.

## Решение

- `docs/` в репозитории — единственный источник истины: ТЗ по разделам (`spec/`), архитектура, ADR по файлу на решение, план, открытые вопросы, риски, глоссарий, журнал изменений, история сессий.
- Любое изменение требований, архитектуры или решения — в том же коммите отражается в `docs/` (раздел ТЗ + ADR + строка в CHANGELOG).
- Граф знаний Graphify по документации и коду — главный инструмент навигации и всегда актуален (порядок работы — D-29).
- В конце каждой сессии — запись в `docs/history/`.

## Последствия

Каждое изменение дороже на шаг документации — это осознанная цена за передаваемость проекта.
