# D-24. Название продукта

- **Статус:** ОТКРЫТО
- **Дата:** 2026-10-25
- **Связано:** `docs/open-questions.md`

## Контекст

«Datascratch» — рабочее название, конфликтующих продуктов поиск не нашёл. Оценка Claude: «scratch» (черновик) удачно, но «Data» уводит в аналитику, «Scratch» ассоциируется со Scratch от MIT; для «премиум»-концепции звучит слишком технично и длинно.

Сгенерированные альтернативы: Mycelia, Weft, Loomnote, Nodal, Synapsa, Cortexa, Thinkwell, Mnemo, Kora, Corvid, Quillmind. Кандидаты по оценке Claude: Kora, Margins, Folio (проверить занятость).

## Решение

Пока не принято. Финальное название — до публикации в App Store. В коде используется рабочее имя; переименование оформить отдельным ADR.
