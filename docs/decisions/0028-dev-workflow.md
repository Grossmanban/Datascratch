# D-28. Процесс разработки: облако + Mac, сборка iOS в CI

- **Статус:** РЕШЕНО (режим работы и CI, пользователь, 2026-10-25); XcodeGen — ПРЕДЛОЖЕНО
- **Дата:** 2026-10-25
- **Связано:** D-19, `docs/development.md`

## Контекст

Claude работает в двух средах: облачные сессии Claude Code (Linux, Xcode нет — iOS-код можно писать, но не собрать) и Mac пользователя (Apple Silicon, Xcode), который пользователь открывает, когда есть возможность. Тестовое устройство — iPad с Apple Pencil Pro.

## Решение

- Смешанный режим: документация, сервер, веб, а также написание iOS-кода — где удобно; сборка, запуск на симуляторе и установка на iPad — на Mac.
- **GitHub Actions собирает iOS-проект и гоняет тесты на macOS-раннере** на каждый push — iOS-код, написанный в облаке, проверяется сразу.
- Xcode-проект генерируется из текстового описания (**XcodeGen**, `project.yml`) — ПРЕДЛОЖЕНО: файл `.xcodeproj` трудно править без Xcode и он часто конфликтует в git.

## Последствия

Ошибки сборки в облачных сессиях видны с задержкой (время CI). Ощущение пера проверяет только пользователь на iPad.
