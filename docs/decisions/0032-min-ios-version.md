# D-32. Минимальная версия iOS/iPadOS — 26

- **Статус:** РЕШЕНО (пользователь, 2026-10-25)
- **Дата:** 2026-10-25
- **Связано:** D-03, D-15, `docs/spec/02-platforms.md`

## Решение

Минимальная версия — **iOS/iPadOS 26** (текущая и предыдущая мажорные версии на момент старта).

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
| --- | --- | --- |
| **26+** | Новейший системный дизайн (Liquid Glass), свежие API TextKit 2 и SwiftUI, меньше условного кода | Старые устройства без обновления не поддерживаются |
| 18+ | Шире охват | Часть визуальных эффектов — условно или вручную |
| 17.5+ | Минимум для функций Pencil Pro | Больше всего ограничений |

## Последствия

`IPHONEOS_DEPLOYMENT_TARGET = 26.0`. Можно без оглядки использовать API iOS 26.
