# D-33. Bundle ID — com.datascratch.app

- **Статус:** РЕШЕНО (пользователь, 2026-10-25)
- **Дата:** 2026-10-25
- **Связано:** D-24

## Решение

Bundle ID приложения — `com.datascratch.app`. У пользователя платный аккаунт Apple Developer. Team ID задаётся на Mac при первой подписи (в репозитории не хранится). Bundle ID можно сменить до первой публикации в App Store (например, при выборе финального названия, D-24).
