# D-34. Вход: email + пароль; пароль же даёт ключ шифрования; ключ восстановления

- **Статус:** РЕШЕНО (пользователь, 2026-10-25); криптографические детали — `docs/architecture/contracts/crypto.md`
- **Дата:** 2026-10-25
- **Связано:** D-04, R-02, `docs/spec/07-encryption.md`

## Контекст

При сквозном шифровании ключ приватных блокнотов выводится из пароля, поэтому пароль нужен в любом случае. Забытый пароль без механизма восстановления = потерянные заметки (R-02).

## Решение

- Вход по **email + паролю**. Один пароль — и для входа, и для шифрования (как в Notesnook).
- Из пароля на устройстве выводятся два независимых ключа: один для входа (сервер хранит только его хэш), другой для шифрования (никогда не покидает устройство). Сервер не может узнать пароль или ключ шифрования.
- При регистрации выдаётся **ключ восстановления**, который пользователь сохраняет. С ним можно задать новый пароль без потери данных.

## Рассмотренные варианты

| Вариант | Итог |
| --- | --- |
| **Email + пароль** | Выбрано: просто, надёжно, понятно |
| + Sign in with Apple | Отдельный пароль шифрования всё равно нужен — путаница |
| + passkeys | Сложно совместить со сквозным шифрованием сейчас; возможно позже |
