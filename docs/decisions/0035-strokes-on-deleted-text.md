# D-35. Пометка на удалённом тексте исчезает вместе с ним

- **Статус:** РЕШЕНО (пользователь, 2026-10-25)
- **Дата:** 2026-10-25
- **Связано:** D-05, R-04, `docs/architecture/contracts/strokes.md`

## Решение

Если помеченный текст удалён (пользователем, агентом или с другого устройства), рукописная пометка исчезает вместе с ним. При частичном удалении штрих «сжимается» до оставшегося текста: точки, привязанные к удалённым символам, не рисуются. Отмена и история версий возвращают и текст, и пометку.

Технически: штрих не стирается из документа в момент удаления текста — он просто не рисуется, пока его якоря указывают на удалённые символы. Поэтому отмена (включая отмену на другом устройстве) возвращает пометку автоматически. Окончательная очистка — при уплотнении истории.

## Рассмотренные варианты

| Вариант | Итог |
| --- | --- |
| **Удалить вместе с текстом** | Выбрано: предсказуемо, просто |
| Прилипать к соседнему символу | Пометка может оказаться не на том слове |
| «Потерянные пометки» | Лишний интерфейс |
