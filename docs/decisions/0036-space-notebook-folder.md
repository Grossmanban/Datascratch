# D-36. Структура: пространство → блокноты → папки

- **Статус:** РЕШЕНО (пользователь, 2026-10-25)
- **Дата:** 2026-10-25
- **Связано:** D-09, D-14, `docs/spec/05-organization-design.md`, `docs/architecture/contracts/document-model.md`

## Решение

- **Пространство** (Личное, Работа, Учёба) содержит несколько **блокнотов**.
- **Блокнот** — единица режима шифрования (приватный / для агентов) и шеринга.
- Внутри блокнота — **вложенные папки** без ограничения глубины и заметки.
- ~~Поперёк — теги, умные теги, избранное, недавние.~~ Заменено D-48 (2026-10-26): всё это — внутри текущего пространства (`0048-isolated-spaces.md`).

В одном пространстве можно держать и приватное, и открытое агентам.

## Рассмотренные варианты

| Вариант | Итог |
| --- | --- |
| **Пространство → блокноты → папки** | Выбрано: гибко |
| Пространство = блокнот | Проще, но нельзя смешивать режимы в одном контексте |
