# D-37. Гости по ссылке рисуют; ссылка живёт до отзыва

- **Статус:** РЕШЕНО (пользователь, 2026-10-25)
- **Дата:** 2026-10-25
- **Связано:** D-13, `docs/spec/08-sharing.md`

## Решение

- Гости со ссылкой на правку могут и писать, и рисовать (пером, пальцем, мышью).
- Ссылка по умолчанию действует **до отзыва**; срок можно задать при создании.
