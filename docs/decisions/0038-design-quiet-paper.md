# D-38. Дизайн-направление — «Тихая бумага», ориентир Craft

- **Статус:** РЕШЕНО (пользователь, 2026-10-25); конкретные значения токенов — ПРЕДЛОЖЕНО (`packages/design-tokens`)
- **Дата:** 2026-10-25
- **Связано:** D-15, D-41, `docs/architecture/contracts/design-tokens.md`

## Решение

Направление «Тихая бумага»: тёплый почти белый фон, глубокие «чернильные» цвета, заголовки с засечками, рукопись выглядит как на хорошей бумаге. Тёмная тема — тёплый графит.

Главный визуальный ориентир — **Craft** (скриншоты пользователя, 2026-10-25): мягкие градиентные подложки, документы-карточки с обложками, боковая панель «Вкладки / Избранное / Папки / Теги», стеклянные плавающие панели, крупная типографика с засечками, контекстные меню вместо кнопок.
