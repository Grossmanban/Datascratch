# D-41. Набор функций по мотивам Craft

- **Статус:** включить функции — РЕШЕНО (пользователь, 2026-10-25); разбивка «MVP / после MVP» — ПРЕДЛОЖЕНО
- **Дата:** 2026-10-25
- **Связано:** D-15, D-38, `docs/spec/12-craft-features.md`

## Контекст

Пользователь прислал скриншоты Craft как ориентир не только по дизайну, но и по функциям: задачи в документах и единый список задач, ежедневные заметки и календарь, обложки и стили документов, документы-карточки, богатые блоки (таблица, канбан, рисунок, скан, доска, Mermaid, код, формулы), коллекции с видами таблица/галерея/канбан, вкладки.

## Решение

Функции включены в ТЗ (`docs/spec/12-craft-features.md`) с предложенной разбивкой по этапам. Перо в тексте остаётся главной фичей (D-05); функции Craft не должны ухудшать его качество.
