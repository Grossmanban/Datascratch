# D-43. Локальная библиотека переносится в аккаунт автоматически

- **Статус:** РЕШЕНО (пользователь, 2026-10-25)
- **Дата:** 2026-10-25
- **Связано:** D-36, `docs/spec/07-encryption.md`, `docs/spec/10-sync.md`

## Контекст

Приложение на iOS работает и без сервера («На этом устройстве»): пространства, блокноты и заметки хранятся локально, ключи блокнотов обёрнуты локальным мастер-ключом. При первом входе в аккаунт (build 5) эти данные оставались в локальной базе: блокноты не создавались на сервере, регистрация документов получала 404, и синхронизация висела в состоянии «Синхронизация…».

## Решение

При входе в аккаунт всё, что создано на устройстве до входа, **автоматически и без вопроса** переносится в аккаунт: пространства, блокноты (ключи переобёртываются ключами аккаунта, блокноты создаются на сервере до старта синхронизации), заметки, вложения, избранное, ежедневный блокнот. Перенос идемпотентен (повторный запуск безопасен, 409 «уже есть» — не ошибка), приветственный документ не дублируется. Срабатывает и для уже вошедших пользователей при следующем запуске.

Ошибка отдельного документа не должна блокировать синхронизацию остальных; статус синхронизации показывает реальное состояние («Синхронизировано», «Ошибка: …», «N не отправлено»).

## Альтернативы

- Перенос с вопросом при входе — лишний шаг; пользователь выбрал молчаливый перенос.
- Раздельное хранение (локальное отдельно от аккаунта) — путает, заметки «пропадают» из вида.
