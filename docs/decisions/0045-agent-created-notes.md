# D-45. Заметка, целиком созданная агентом, не подсвечивается построчно

- **Статус:** РЕШЕНО (пользователь, 2026-10-26)
- **Дата:** 2026-10-26
- **Связано:** D-10 (`0010-agent-edits.md`), `docs/spec/04-editor.md`, `docs/spec/09-agents-api.md`, контракты `document-model.md` (NoteMeta), `agents-api.md`

## Контекст

По D-10 весь текст, вставленный агентом, получает метку `agentEdit` и подсвечивается до «принять». Пользователь открыл заметку, которую Claude создал с нуля, и увидел её целиком зелёной с подчёркиваниями — подсветка ничего не различает (весь текст агента) и только мешает читать.

## Решение

- `create_note` **не ставит** метку `agentEdit` на содержимое новой заметки. Вместо этого в `NoteMeta` заметки пишется `createdByAgent: { agentId: <grantId>, agentName, at }`.
- Клиенты показывают в начале такой заметки спокойную полоску «Создано агентом {agentName}» с кнопкой «Понятно»; «Понятно» ставит `createdByAgent = null` (полоска исчезает на всех устройствах).
- Правки агента **в существующих** заметках (`edit_note`, в том числе вставки в заметку, созданную агентом, после «Понятно») подсвечиваются по D-10, как раньше; у заметки с такими правками — полоска «Правки агента · Принять все» и принятие по блоку (`spec/04`).
- Уже созданные заметки с метками остаются как есть — их снимает «Принять все».

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
| --- | --- | --- |
| **Без построчной подсветки, полоска «Создано агентом»** | Заметку удобно читать; видно, откуда она | Нужно поле в `NoteMeta` |
| Подсвечивать всё до «Принять все» | Ничего менять не надо | Вся заметка зелёная, подсветка ничего не сообщает |
