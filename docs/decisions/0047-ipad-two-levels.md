# D-47. iPad: не больше двух колонок — уровни «сайдбар → список → документ»

- **Статус:** РЕШЕНО (пользователь, 2026-10-26); заменяет раскладку из трёх панелей в D-44
- **Дата:** 2026-10-26
- **Связано:** D-44 (`0044-ipad-column-rules.md`), D-15, `docs/spec/05-organization-design.md`

## Контекст

Build 9–10 в альбоме показывали три панели сразу (сайдбар | список | документ). Пользователь: кнопки «на весь экран» две одинаковые (у списка и у документа), крестик в средней панели закрывает правую панель с текстом, «назад/вперёд» непонятно к чему относятся — «всё равно плохо выглядит». Предложение пользователя: первая панель никогда не видна вместе с третьей; уровни идут по порядку — с первой видна вторая, со второй — третья.

## Решение

- Три уровня: **1 — сайдбар**, **2 — список** (или «Задачи», «Календарь»), **3 — документ**. На экране одновременно не больше **двух соседних** уровней: 1+2 или 2+3. Сайдбар и документ вместе не показываются никогда.
- Документ не открыт → **сайдбар | список**. Открыли документ → **список | документ** (сайдбар уходит плавным сдвигом влево). Кнопка сайдбара в этом состоянии сдвигает обратно к **сайдбар | список**, документ остаётся открытым и возвращается при выборе.
- «Назад» (‹) всегда поднимает на уровень выше: из «список | документ» → «сайдбар | список» (документ закрывается). Отдельных «вперёд» в шапках колонок нет.
- У каждой кнопки одно место и одно действие: «На весь экран» — **только** у документа (документ на всю ширину; выход — в ту же пару колонок); × — только у документа и закрывает **сам документ**; у списка — свои действия (новая заметка, вид, поиск), кнопок документа нет.
- Узкая ширина (портрет без места на две колонки, Split View, iPhone) — один уровень на экране, стек с «назад».
- «Задачи» и «Календарь» — уровень 2; открытый из них документ — уровень 3 по тем же правилам.

## Рассмотренные варианты

| Вариант | Плюсы | Минусы |
| --- | --- | --- |
| **Две соседние колонки по уровням (предложение пользователя)** | Понятно, где ты; нет дублей кнопок; документу больше места | Сайдбар и документ одновременно не увидеть |
| Три панели (D-44) | Всё сразу | Тесно, дубли кнопок, путаница — отзыв пользователя |
