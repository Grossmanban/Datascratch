# D-48. Пространства полностью изолированы

- **Статус:** РЕШЕНО (пользователь, 2026-10-26); уточняет D-36 («поперёк — теги, избранное, недавние» больше не действует)
- **Дата:** 2026-10-26
- **Связано:** D-36 (`0036-space-notebook-folder.md`), D-14, `docs/spec/05-organization-design.md`, `docs/spec/12-craft-features.md`, `docs/architecture/contracts/document-model.md`

## Контекст

Пользователь на iPhone видел в пространстве «Личное» избранные документы, открытые вкладки, задачи и записи календаря из «Работы». Его слова: пространства «должны быть полностью разделены… это же типа один рабочий, условно, а другой личный».

## Решение

Пространство — отдельный рабочий контекст. Всё, что показывает приложение, относится **только к текущему пространству**:

- **Избранное** и **недавние** — только документы, папки и блокноты текущего пространства.
- **Вкладки** — свой набор открытых вкладок и своя активная вкладка у каждого пространства; при переключении пространства вкладки меняются на его вкладки и возвращаются, когда вернулись.
- **Задачи** (Входящие / Сегодня / Скоро / Все) — только из документов текущего пространства; «Входящие» — свои у каждого пространства.
- **Календарь** и **ежедневные заметки** — свой блокнот ежедневных заметок у каждого пространства; в ленте дней только задачи и заметки текущего пространства.
- **Теги** — список и счётчики только по текущему пространству.
- **Поиск** и палитра команд — только в текущем пространстве.
- **Все документы**, **корзина** — только текущее пространство.
- Подсказки ссылок `[[` — только документы текущего пространства.

Что остаётся общим для аккаунта: настройки приложения (тема, язык, перо), сам аккаунт, ключи, устройства, доступы агентов (агентам выдаются блокноты, `spec/09-agents-api.md`).

### Детали (ПРЕДЛОЖЕНО, ждёт подтверждения)

- **Старая ссылка на документ из другого пространства** (созданная до D-48 или при переносе) открывается и переключает пространство на пространство этого документа; новых таких подсказок нет.
- **Перенос** блокнота или заметки в другое пространство — явное действие «Переместить в пространство…»; после переноса избранное/вкладка уходят вместе с документом.
- Поиска «по всем пространствам» нет; если понадобится — отдельный явный переключатель в поиске, по умолчанию выключен.

## Данные

Принадлежность считается от блокнота: документ → его блокнот → `NotebookRef.spaceId`. Отдельного поля в элементах избранного и вкладок не нужно — клиенты фильтруют по пространству. Активная вкладка и блокнот ежедневных заметок становятся «по пространству» (`settings.activeTabBySpace`, `settings.dailyNotebookBySpace`; контракт `document-model.md` §2). Старые общие `activeTab` и `dailyNotebookId` при первом запуске новой версии относятся к пространству своего документа/блокнота.

## Рассмотренные варианты

| Вариант | Итог |
| --- | --- |
| **Полная изоляция (решение пользователя)** | Выбрано: рабочее и личное не смешиваются нигде |
| Общие избранное/теги/задачи поперёк пространств (D-36) | Отклонено: в «Личном» видно рабочее |
| Переключатель «показывать всё» | Не нужен по умолчанию; возможен позже только для поиска |
