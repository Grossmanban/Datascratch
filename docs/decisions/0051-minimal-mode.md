# D-51. Минимализм (KISS): по умолчанию — только заметки; задачи, календарь и вкладки — в «расширенном режиме»

- **Статус:** РЕШЕНО (пользователь, 2026-10-26); поправка 2026-11-02 — вкладки вернулись в обычный режим
- **Дата:** 2026-10-26
- **Связано:** D-14, D-15, D-41 (функции по мотивам Craft), D-48, `docs/spec/05-organization-design.md`, `docs/spec/12-craft-features.md`, заметка «Стратегия продукта — черновик»

## Контекст

Пользователь: «давай сделаем приложение минималистичным: уберём календарь, задачи и так далее — будут чисто заметки с хорошим форматированием, с пером, с доступом для ИИ-агентов, чтобы можно было поделиться… Философия KISS. Уберём открытые вкладки, но оставим пространства». Сделанную работу не терять: не удалять код, а спрятать за переключателем «расширенный режим» в конфигурации сборки — «чтобы программа стала как Notesnook».

## Решение

**Обычный режим (по умолчанию в сборках):**
- Пространства (D-48), блокноты, папки, заметки; теги; избранное; поиск и палитра ⌘K.
- Редактор целиком: форматирование, таблицы, код, формулы, Mermaid, выноски, `[[ссылки]]`, картинки и файлы, рисунок, **перо в тексте**.
- Чек-листы в тексте остаются (это форматирование): отметить/снять. Даты задач и меню переноса — только в расширенном режиме; уже проставленные даты сохраняются в данных и показываются как обычный текст-метка без действий.
- Доступ ИИ-агентов (MCP), шеринг по ссылке; совместная работа по аккаунтам — в планах.
- История версий, шифрование, синхронизация.

**Только в расширенном режиме:**
- Экран «Задачи» (Входящие / Сегодня / Скоро / Все), «Входящие», даты и дедлайны задач, напоминания.
- «Календарь» и ежедневные заметки.
- Вкладки и всё из §12.6 про вкладки (обзор, «+N», закреплённые, тихая уборка).
- Коллекции (§12.5) и будущие «командные» задачи (исполнители, канбан, экран руководителя).

**Как устроен переключатель:**
- Один флаг `extendedMode` на всех клиентах, значение задаётся **конфигурацией сборки**: iOS — `DS_EXTENDED_MODE` в xcconfig → ключ `DSExtendedMode` в Info.plist; веб — `VITE_DS_EXTENDED_MODE`. По умолчанию `false`.
- Код расширенного режима **не удаляется и не комментируется** — он компилируется всегда, скрыт проверкой флага в одном месте (реестр функций), чтобы не «гнил» и не ломал сборку.
- Тесты расширенных функций продолжают выполняться: UI-тесты включают режим аргументом запуска (`-ds-extended-mode YES`) / переменной окружения.
- Данные не меняются и не мигрируют: заметки, задачи с датами, вкладки в документе аккаунта сохраняются как есть; клиент в обычном режиме их не трогает.

## Рассмотренные варианты

| Вариант | Итог |
| --- | --- |
| **Флаг сборки, код живой и под тестами** | Выбрано: ничего не теряется, легко вернуть |
| Закомментировать код | Отклонено: комментированный код быстро ломается и не проверяется |
| Удалить | Отклонено: пользователь хочет сохранить работу |
| Переключатель в настройках для всех | Отклонено пока: KISS — пользователь не должен видеть лишнего |

## Поправка 2026-11-02: вкладки — в обычном режиме

Владелец в списке «Баги»: «вкладки добавить, но красиво, элегантно и удобно»; на вопрос — «да». Вкладки (`features.tabs` / `Features.tabs`) включены во всех сборках; задачи и календарь остаются в расширенном режиме.

- **Веб:** полоса вкладок, «+N», обзор, закреплённые, «Недавно закрытые», тихая уборка — как в §12.6, без изменений.
- **iPad:** тихая полоса над документом, когда открыто два документа и больше: активная вкладка на светлой подложке с ×, остальные — названия с точкой цвета блокнота; полоса сама прокручивается к активной; кнопка-счётчик справа (и ⌘⇧\) открывает обзор карточками с «Закрыть остальные». Раздел «Вкладки» в боковой панели убран — его заменила полоса.
- **iPhone:** кнопка-счётчик в панели документа открывает тот же обзор (как в Safari).
- Закреплённые вкладки, «Недавно закрытые» и тихая уборка на iOS — следующим шагом (модель iOS пока хранит только список открытых).
