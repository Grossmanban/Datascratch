# D-52. Картинки по ссылке при вставке в вебе — через сервер

- **Статус:** РЕШЕНО (пользователь, 2026-10-27)
- **Дата:** 2026-10-27
- **Связано:** D-04 (шифрование), `docs/architecture/contracts/api.md` («Вложения»), `docs/spec/04-editor.md` («Вставка с форматированием»), `apps/web/src/lib/securityHeaders.ts`

## Контекст

При вставке куска сайта в буфере часто лежат не картинки, а их адреса (`<img src="https://…">`). Веб-версия не может их скачать: строгая политика безопасности (`connect-src 'self'`) запрещает обращения к чужим сайтам — это главный барьер, который не даёт внедрённому коду вынести расшифрованные заметки наружу. Без решения такие картинки остаются ссылками. iOS-приложение скачивает картинки само и этого ограничения не имеет.

## Решение

Веб просит **наш сервер** скачать картинку: `POST /v1/fetch-image` (контракт — `api.md`). Сервер возвращает байты картинки; веб сразу шифрует их ключом заметки и загружает как обычное вложение. Политика безопасности веба **не ослабляется**.

Ограничения сервера (обязательны):
- только для вошедшего пользователя; ограничение частоты (по умолчанию 60 запросов в минуту на аккаунт);
- только `http`/`https`, порты 80/443; адрес разрешается в IP **до** запроса, запрещены частные, локальные, служебные и зарезервированные сети (IPv4 и IPv6: 10/8, 172.16/12, 192.168/16, 127/8, 169.254/16, 100.64/10, 0/8, ::1, fc00::/7, fe80::/10, IPv4-mapped и т. п.); соединение идёт на проверенный IP (защита от подмены DNS);
- не больше 3 переадресаций, каждая проверяется так же;
- только картинки: `Content-Type: image/*` и проверка сигнатуры файла (PNG, JPEG, GIF, WebP, HEIC/AVIF, SVG — **SVG не принимается**);
- не больше 20 МБ (обрыв при превышении), таймаут 15 с;
- без cookies и авторизации к чужому сайту, без `Referer`;
- **адреса не пишутся в журналы** (только счётчики и коды ошибок).

Минус (принят пользователем): сервер узнаёт адрес вставленной картинки, но не содержимое заметки; сама картинка шифруется на устройстве, как всё остальное.

## Рассмотренные варианты

| Вариант | Итог |
| --- | --- |
| А. Оставить ссылками | Безопасно, но картинки с сайтов теряются |
| Б. Разрешить вебу обращаться к любым сайтам (`connect-src https:`) | Отклонено: ослабляет главную защиту от выноса данных |
| **В. Скачивание через сервер со строгими ограничениями** | **Выбрано** |
