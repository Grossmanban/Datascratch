# Глоссарий

- **Живой штрих** — рукописная пометка, чьи точки привязаны к символам текста и пересчитываются при перекладке (D-05).
- **Перекладка (reflow)** — перенос текста по строкам заново при смене ширины, повороте или правке.
- **Якорь** — то, к чему привязан штрих: диапазон текста, абзац (поля), блок рисования или картинка.
- **Относительная позиция (RelativePosition)** — метка CRDT на конкретный символ, которая остаётся на нём при любых вставках и удалениях вокруг, в том числе с других устройств.
- **CRDT** — структура данных, позволяющая сливать правки с разных устройств без конфликтов. У нас — Yjs (веб, сервер) и Yrs (iOS) (D-31).
- **Yjs / Yrs** — библиотека CRDT для JavaScript и её версия на Rust (используется в iOS через Swift-обёртку); бинарный формат совместим.
- **Обновление (update)** — бинарная запись одной правки документа Yjs; именно обновления шифруются и пересылаются через сервер.
- **Снимок (snapshot)** — уплотнённое состояние документа на момент времени; основа истории версий и уплотнения истории.
- **Сквозное шифрование (E2E)** — сервер хранит только шифр и не может прочитать содержимое.
- **Приватный блокнот** — блокнот со сквозным шифрованием, агентам недоступен.
- **Блокнот «для агентов»** — блокнот, ключ которого хранится на сервере, чтобы внешние агенты могли читать и править его по токену.
- **MCP** — Model Context Protocol, стандарт подключения инструментов и данных к ИИ-агентам.
- **ADR** — Architecture Decision Record, файл с одним решением и его обоснованием (`docs/decisions/`).
- **Пространство** — верхний уровень организации (Личное, Работа, Учёба).
- **Умный тег** — сохранённый фильтр, который автоматически собирает заметки по условиям.
- **Universal Links** — механизм iOS, открывающий веб-ссылку сразу в приложении, если оно установлено.
- **TextKit 2** — системный движок вёрстки текста в iOS; даёт позиции глифов, к которым привязываются штрихи.
- **PencilKit / PKCanvasView** — системный холст рисования Apple; не умеет привязку к тексту, поэтому у нас свой слой пера.
- **Predicted / coalesced touches** — предсказанные и промежуточные точки касания пера в iOS; нужны для минимальной задержки и плавности.
- **ProMotion** — экраны Apple с частотой до 120 Гц.
- **PWA** — веб-приложение, которое устанавливается как обычное и работает офлайн.
- **Self-hosting** — установка сервера на собственную машину (`docker compose up`).
- **Row-Level Security (RLS)** — правила PostgreSQL, ограничивающие доступ к строкам таблиц на уровне базы.
- **pg-boss** — очередь фоновых задач поверх PostgreSQL (вместо Redis).
- **XcodeGen** — генератор Xcode-проекта из текстового файла `project.yml`.
- **Graphify** — инструмент, строящий граф знаний по документации и коду для навигации ИИ (`graphify-out/`).
- **Тестовые векторы** — общие наборы «вход → ожидаемый выход», которые прогоняются и в Swift, и в TypeScript, чтобы гарантировать совместимость.
