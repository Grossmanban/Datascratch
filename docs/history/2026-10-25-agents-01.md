# Поток agents, сессия 01 — 2026-10-25

Сессия-исполнитель потока **agents** (D-39), ветка `claude/agents`.

## Что сделано

- Пакет `@datascratch/agents` — Fastify-плагин для сервера:
  - **MCP** на официальном TypeScript SDK **v2** (`@modelcontextprotocol/server` 2.4; на дату сессии это стабильная линия SDK, реализует спецификацию MCP 2026-07-28 и обслуживает клиентов 2025 года через совместимый путь без состояния). 12 инструментов: `list_spaces`, `list_notebooks`, `list_notes`, `search_notes`, `read_note`, `get_handwriting_image`, `get_backlinks`, `list_tasks`, `create_note`, `edit_note`, `add_comment`, `update_task`.
  - **OAuth 2.1**: метаданные ресурса (RFC 9728) и сервера (RFC 8414), Client ID Metadata Documents (по новой спецификации — основной способ) и динамическая регистрация (для совместимости), PKCE S256, `resource` (RFC 8707), `iss` в ответе (RFC 9207), ротация refresh-токенов, отзыв, step-up 403 `insufficient_scope` для пишущих инструментов. Экран согласия — HTML в стиле «Тихая бумага» (светлая/тёмная тема, проверен скриншотами).
  - **Статические токены** и `/v1/agent-tokens` (создание, список вместе с OAuth-подключениями, отзыв, журнал).
  - **REST** `/v1/agent/*` — те же операции.
  - **Правки** — операции над блоками по `blockId`, атомарно, метка `agentEdit`, обновления Yjs через `context.data.applyUpdate` с указанием агента; рукописные якоря сохраняются (минимальная замена текста; при перемещении блока штрихи заменяются копиями с новыми якорями).
  - **Рендер рукописи в PNG** (`@napi-rs/canvas`, встроенные шрифты Inter/Newsreader), правила `strokes.md` (толщина, нажим, наклон, маркер под текстом, разрыв по строкам, D-35), кэш.
  - Журнал всех действий, лимиты запросов в памяти процесса, понятные ошибки для моделей.
- Тесты (vitest, 36): модель документа и Markdown, правки и сохранность рукописи, права и режимы блокнотов, MCP через официальный клиент SDK, полный OAuth-поток клиентом SDK (DCR и CIMD), REST, лимиты, эталонные PNG с допуском. CI `.github/workflows/agents.yml` — зелёный.
- Документы: черновик контракта `docs/architecture/contracts/agents-api.md`, `spec/09` по факту, инструкция пользователя `docs/guides/connect-ai-agents.md`, фрагмент журнала.

## Что решили (технически, внутри потока)

- SDK v2 вместо v1 (`@modelcontextprotocol/sdk` 1.x) — v2 стабильна и следует актуальной спецификации.
- Одно «разрешение» (grant) на статический токен или OAuth-подключение; повторная авторизация того же клиента обновляет его.
- Пока `@datascratch/shared` не опубликован, модель документа, кодек штрихов и Markdown — локально в `src/doc/` (помечено `TODO(core)`).

## Открытые вопросы (отправлены координатору)

1. Имена блокнотов и пространств живут в зашифрованном мастер-ключом документе `account` — сервер их не знает. Предложение: дублировать в `meta` документа `notebook` (`name`, `icon`, `space`).
2. Метки без атрибутов: контракт говорит `true`, y-prosemirror пишет `{}` — читать оба.
3. Экран согласия требует cookie-сессию веба на домене сервера или `loginUrl` веба (потоки server, web-app).
