# 2026-10-25 · поток core · сессия 01

Ветка `claude/core`. Задание — фундамент TypeScript-части: инструменты монорепо, `packages/shared`, `packages/test-vectors` (D-39).

## Что сделано

- **Монорепо:** pnpm workspace + turbo (`build`, `typecheck`, `lint`, `test`), общий `eslint.config.js` (flat, typescript-eslint), Prettier, `.editorconfig`, строгий `tsconfig.base.json`. CI `.github/workflows/ts.yml`: установка, проверка формата, затем turbo по всем пакетам `apps/*` и `packages/*` (новые пакеты подхватываются сами).
- **`@datascratch/shared`** (ESM, tsup, подпути `contracts`, `crypto`, `ids`, `document`, `strokes`, `sync`):
  - `contracts/` — типы и zod-схемы документа, штрихов, сообщений синхронизации, тел REST API, константы и строки `ad`;
  - `crypto/` — libsodium-wrappers-sumo строго по `crypto.md`, плюс сценарии регистрации, смены пароля и восстановления;
  - `ids` — монотонный UUIDv7;
  - `document/` — фабрики трёх видов документов, типизированный доступ к записям, конвертер PM-JSON ↔ Yjs, побайтно совпадающий с y-prosemirror (проверено тестом), извлечение задач/ссылок/тегов/текста, экспорт в Markdown (рукопись — ссылки-заглушки), атомарные блочные операции для агентов с меткой `agentEdit`;
  - `strokes/` — упаковка точек, якоря с проверкой удаления (с учётом redone), раскладка по строкам при заданной платформой геометрии глифов, толщина, хранение, перепривязка якорей после отмены (`attachAnchorRebase`), восстановление версии с пересчётом якорей, учёт `orphanedAt`;
  - `sync/` — `SyncClient` (браузер/Node WebSocket, зашифрованная офлайн-очередь через `SyncStorage`, догоняющая подписка от `lastSeq`, переподключение с backoff и jitter, снимки по порогам, слишком большое обновление уходит снимком, awareness) и `MemorySyncHub` — исполняемый эталон серверной стороны протокола для тестов любых клиентов.
- **`@datascratch/test-vectors`:** генератор на TS и 14 JSON-файлов векторов; README с инструкцией для Swift. `shared` проверяет себя по всем векторам; `pnpm --filter @datascratch/test-vectors test` в CI падает, если векторы устарели.
- Тесты: 91 в `shared`, CI зелёный.

## Что решили (через координатора)

Предложения потока приняты в контракты 2026-10-25:

- метки в `Y.XmlText` — объект атрибутов (`{}` у меток без атрибутов), читатели принимают и `true`, и ключи `имя--хэш`; атрибуты узлов со значением `null` не хранятся;
- поля `Device`, `Share`, `AgentToken` в `api.md`; лимиты синхронизации — MiB декодированных байт;
- `ack` на снимок несёт `seq = baseSeq`; сервер обязан рассылать обновления документа в порядке `seq`;
- штрих: изменяемы `anchors` и `hidden`; перепривязка якорей после отмены/повтора и при восстановлении версии; окончательное удаление осиротевших штрихов по локальному `orphanedAt` (D-35).

Найдено при работе: ссылки redone в Yjs локальны — без перепривязки отменённое удаление текста возвращало пометку только на одном устройстве.
