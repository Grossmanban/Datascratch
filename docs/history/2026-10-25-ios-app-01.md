# ios-app-01 — 2026-10-25: оболочка iOS-приложения

Сессия-исполнитель потока **ios-app** (D-39). Ветка `claude/ios-app`. Координатор — исходная сессия.

## Что сделано

1. **Проект.** `apps/ios/project.yml` (XcodeGen): приложение Datascratch, `com.datascratch.app`, iOS/iPadOS 26, iPhone + iPad, Swift 6 с изоляцией MainActor по умолчанию, String Catalog ru/en, иконка-заглушка (светлая/тёмная), Associated Domains `applinks:$(DS_WEB_HOST)`, схема `datascratch://`, многооконность. Team ID — только через `Config/Local.xcconfig` (в git не хранится). `scripts/generate.sh` подключает существующие пакеты `Packages/DSCore|DSEditor|DSDesign`.
2. **Оболочка в стиле Craft.** `NavigationSplitView`: боковая панель (вкладки, переключатель пространств, Все документы, Задачи со счётчиком, Календарь, Избранное, блокноты с вложенными папками, цветами и значками, теги, корзина, статус синхронизации, настройки), сетка карточек с обложками / список, экран документа (обложка, подложка, «бумага», шрифт и ширина, бэклинки, история версий, перенос, шеринг), палитра ⌘K с нечётким поиском и стрелками, контекстные меню, перетаскивание документов в папки, шорткаты iPad (⌘N, ⇧⌘N, ⌘K, ⌘1–4, ⇧⌘T, ⌘,), отдельное окно документа (Stage Manager), на iPhone — кнопка «новая заметка» под большим пальцем.
3. **Онбординг (D-34).** Регистрация → показ ключа восстановления (`DS1-` + 13 групп Crockford Base32, контракт crypto §4) → подтверждение двух случайных групп; вход; восстановление по ключу; смена пароля. Ключ хранится в Keychain до подтверждения, чтобы не потерять его при закрытии приложения (R-02).
4. **Организация (D-36).** Пространства → блокноты → папки; создание блокнота с выбором режима (приватный / для агентов) и честным предупреждением; смена режима с подтверждением; корзина 30 дней с автоочисткой.
5. **Задачи и календарь (spec/12).** Входящие / Сегодня / Скоро / Все, группировка, просроченные, контекстное меню (Сегодня / Завтра / След. неделя / Дата…, дедлайн, выполнить, отменить, открыть документ, перенести, удалить), свайпы. Календарь: лента дней, заметка дня по требованию, задачи дня.
6. **Шеринг и ссылки.** Создание/копирование/отзыв ссылок `https://<host>/s/<id>#k=<ключ>` с правом и сроком; открытие Universal Links и `datascratch://` (разбор маршрутов).
7. **Настройки.** Аккаунт, синхронизация, устройства, токены агентов (выбор блокнотов «для агентов», показ токена один раз), рисование пальцем (D-06, по умолчанию выключено), тема, стиль новых документов, о приложении.
8. **Тесты и CI.** Юнит-тесты (Swift Testing): ключ восстановления, UUIDv7, теги/ссылки, даты, хранилище (папки, корзина, версии, сохранение), индекс задач, маршруты, аккаунт, шеринг. UI-тесты: регистрация с подтверждением ключа, создание заметки, палитра, настройка пера. `.github/workflows/ios-app.yml` — сборка и тесты на симуляторах iPad и iPhone (macos-26, Xcode 26).
9. **TestFlight без Mac.** `.github/workflows/ios-release.yml`: архив, облачная подпись через ключ App Store Connect API, загрузка в TestFlight; без секретов — пропуск. Пошаговая инструкция для пользователя — `apps/ios/RELEASE.md`.

## Временные замены

Пакетов `DSCore`, `DSEditor`, `DSDesign` в `main` ещё нет. Приложение работает на своих заменах с тем же разрезом интерфейсов: `LibraryStore` (JSON вместо Yrs + GRDB), `LocalAccountService` (учётка на устройстве, SHA-256 вместо Argon2id), локальные шеринг и токены, блочный редактор-заглушка, `Theme` с токенами из контракта. Таблица — в `apps/ios/README.md`.

## Продолжение: интеграция пакетов

- **DSDesign** подключён: цвета и оттенки из сгенерированных токенов, `DSDateChip` (правила дат как в вебе), `DSTaskCheckbox`, отладочный `DSShowcase`.
- **DSCore**: `CoreLibrary` — библиотека в документах `account`/`notebook`/`note` (Yrs), обновления в `LocalStore` вместе с очередью отправки, ключи блокнотов и заметок через `KeyRing`, перенос старого JSON. Найдены и исправлены две ошибки: (1) первое обновление документа аккаунта создавалось до подписки на сохранение — без него Yjs не применяет последующие обновления; (2) Keychain недоступен в неподписанной сборке симулятора (-34018) — там ключи держатся в памяти.
- Безопасность данных: тело заметки пишется точечно по `blockId`; полная перезапись — только если в документе нет блоков, которые временный редактор не умеет показывать (тест `editsDoNotTouchForeignBlocks`).
- **DSEditor**: экран заметки с `EditorView` над `CoreEditorDocument`, стеклянная панель пера, рисование пальцем (на iPhone включено по умолчанию в инструментах пера, режим «Текст» по умолчанию — D-06 соблюдён). Проверено пробной сборкой с пакетом из ветки ios-editor; включится, когда пакет попадёт в main.
- CI: ios-app.yml собирает приложение с пакетами из `main`; бинарный Yrs берётся из релиза DSCore.

- **Серверный режим** (при заданном `DS_SERVER_URL`): вход, регистрация, восстановление и смена пароля через `DSCore.AccountService`; `SyncEngine` + `SyncClient` (документы передаются движку, статус — в индикатор, переподключение при появлении сети); `POST /notebooks` и смена режима до регистрации документов; шеринг (ключ — после `#`), устройства и токены агентов через `APIClient`. Без сервера всё работает локально.
- **TestFlight:** первая сборка (build 1) загружена пользователем через `ios-release.yml`. Добавлены страховочные шаги: `scripts/asc.py` (JWT через openssl) — идемпотентная регистрация Bundle ID с Associated Domains и понятная ошибка, если нет записи приложения в App Store Connect. Нормализацию ключа `.p8` (вставка с телефона) сделал координатор.
- Проба DSEditor (временная ветка `probe/ios-app-editor`): приложение собирается и проходит тесты с редактором из ветки ios-editor.

## Продолжение: правки по сборке 1 (для build 2)

- Тема: `AppSettings.applyAppearanceToWindows()` ставит стиль всем окнам сцены — листы и UIKit-хосты меняются сразу; текст на акцентных кнопках — токен `onAccent` (в тёмной теме тёмный текст на светлом акценте). Тесты `AppearanceUITests` (тёмная тема, русский интерфейс) сохраняют скриншоты; CI выгружает их артефактом `screenshots-*` и проверяет `ru.lproj` в бандле.
- Обложки (spec/12 §12.7, решение пользователя): только своё изображение — «… → Обложка»: «Выбрать фото…» (PhotosPicker), «Выбрать файл…», «Вставить изображение», «Сдвинуть кадр…», «Убрать обложку». `CoverImages` уменьшает картинку (обложка ≤ 2400 px, миниатюра 480 px, JPEG) и хранит файлы по id вложения в `Application Support/Attachments` — там же, где их ждёт `DSCore.AttachmentManager`; с сервером файлы добавляются и загружаются как зашифрованные вложения заметки, на другом устройстве скачиваются при показе. В документе — `meta.cover {attachmentId, offsetY}`, в индексе блокнота — `NoteMeta.coverThumb`. Шапка ≤ ⅕ высоты экрана; на карточке и в списке — миниатюра. Готовые градиенты и выбор подложки убраны из интерфейса; градиентная обложка из сборки 1 (её поставил пользователь) по-прежнему показывается, пока её не заменят или не уберут. Миграцию, удалявшую эту обложку, я сначала сделал, ошибочно сочтя её автодобавленной, — и убрал до слияния. В нативном редакторе шапка стоит над текстом и не прокручивается вместе с ним: у `EditorView` нет прокручиваемого заголовка (просьба к ios-editor).
- Ключ восстановления (spec/07, решение пользователя): на экране проверки — «Пропустить» с предупреждением; ключ остаётся в Keychain этого устройства («Настройки → Аккаунт → Ключ восстановления»: показать, скопировать, проверить); пока не проверен — строка-напоминание в настройках. При выходе из аккаунта ключ удаляется с устройства. На другом устройстве (вход, а не регистрация) ключа нет — строка не показывается.
- Задачи: `DSSegmentedControl` на стекле над списком, группы — карточки без разделителей, `DSTaskRow` (крупный чекбокс с анимацией и откликом), одна компактная дата (срок, иначе план; в «Сегодня» и «Предстоящих» даты нет — её даёт раздел), источник не дублируется в «Все», пустые состояния — `DSEmptyState`. Свайпы и контекстное меню сохранены.
- Временный редактор: подсказка только на пустом документе или текущей пустой строке. В DSEditor поведение подсказки — зона ios-editor.
