# Сессия 01 — 2026-10-25: стек и развёртывание репозитория

Первая сессия в Claude Code (облачная). Вход — передаточный документ `2026-10-25-handoff.md`.

## Что обсудили и решили

1. **Среда.** Mac на Apple Silicon, iPad с Apple Pencil Pro. Работаем в смешанном режиме: часть — в облаке (без Xcode), сборка и проверка — на Mac, когда пользователь его открывает. Предложено собирать iOS в GitHub Actions на macOS (D-28).
2. **Ресурсы VPS.** Пользователь спросил о нагрузке. Ответ: для одного человека и узкого круга — самый дешёвый нормальный VPS (2 ядра, 2–4 ГБ, ~5–10 €/мес), сервер в простое почти не нагружен, нужен только с этапа 3.
3. **Redis** — пользователь спросил, зачем он. Нужен только при нескольких копиях сервера. Вычеркнули (D-25). На будущее — только при платном хостинге и большой нагрузке; сначала хватит PostgreSQL LISTEN/NOTIFY.
4. **База данных** — пользователь спросил, почему PostgreSQL, и отдельно — почему не MySQL. Разобрали SQLite, MySQL, MongoDB. Оставили PostgreSQL: Row-Level Security для прав агентов, транзакционные миграции, очередь и уведомления без Redis, лицензия, запас под возможный платный хостинг (D-30).
5. **MinIO** — не нужен: файлы в папке на диске, внешнее S3 опционально (D-26).
6. **Yjs** — разобрали Automerge, Loro, OT, last-write-wins. Оставили Yjs/Yrs; слабое место — Swift-обёртка Yrs, проверяем уже в прототипе пера (D-27, D-31).
7. **Итог:** стек подтверждён (D-21, D-22 — РЕШЕНО).
8. **Graphify** — пользователь: должен быть главным и всегда актуальным, документация — такой, чтобы любой новый ИИ понял всё идеально. Выяснили, что git-хук Graphify обновляет только структурный слой графа (код, файлы и заголовки документов); смысловой слой по документам — только проходом ИИ (`/graphify . --update`). Зафиксировали порядок работы (D-29).
9. Пользователь спросил о сомнениях, которые могут «сыграть плохую шутку». Ответ оформлен в `docs/risks.md` (R-01…R-13); ключевые — потеря пароля при шифровании, неизменяемость форматов данных, штрихи на удалённом тексте, рост истории, объём проекта.

## Что сделано

- Развёрнута документация по утверждённой структуре, ADR D-01…D-31.
- `CLAUDE.md` с правилами и «определением готово».
- Graphify: навык в проекте, хуки Claude Code, стартовый хук для облачных сессий, `.graphifyignore`, граф построен и закоммичен.
- Скелет монорепозитория с README в каждой части.

## Заметки для следующих сессий (Graphify)

- Первая полная сборка: 61 документ → 668 узлов. Структурный слой (заголовки) строится функцией `extract` и для `.md` тоже — его надо включать в сборку вместе со смысловым, иначе граф получится беднее, чем после git-хука.
- Инкрементальное обновление по 4 изменённым документам проверено. При перезаписи Graphify защитно отказался: смысловые узлы изменённых файлов получили новые имена. Проверили, что все «пропавшие» узлы — из изменённых файлов, и подтвердили замену (`to_json(..., force=True)`). Если «пропадают» узлы из **неизменённых** файлов — не подтверждать, разбираться.
- Названия групп при пересборке переносятся со старого графа по совпадению узлов.
