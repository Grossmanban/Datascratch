# 2026-10-25 — поток web-app, сессия 01

## Что сделано

- Создано приложение `apps/web`: Vite + React 19 + TypeScript, PWA (vite-plugin-pwa, офлайн-кеш оболочки), TanStack Router, Zustand + TanStack Query, i18n ru/en (i18next), Tailwind 4 + Radix + Motion.
- Авторизация по `crypto.md`/`api.md`: регистрация с показом ключа восстановления и подтверждением (4 последних символа), вход, восстановление по ключу, смена пароля, устройства, удаление аккаунта. Argon2id — в Web Worker.
- Локальные данные — Dexie: обновления Yjs, исходящая очередь, очередь REST-операций, индекс задач и заметок; поиск MiniSearch.
- Движок синхронизации по `sync-protocol.md` (hello/subscribe/push/ack/snapshot/awareness, переподключение, офлайн).
- Оболочка в стиле Craft: пространства, Все документы, Задачи, Календарь, Вкладки, Избранное, Папки (дерево, цвета, перетаскивание), Теги, Корзина; сетка карточек с обложками-градиентами и список; палитра ⌘K; контекстные меню; пустые состояния; тёмная тема; мобильная шторка.
- Вложения по crypto.md §6 (куски по 1 МиБ, офлайн-кеш, фоновая докачка) и обложки документов с миниатюрами в карточках.
- Экран документа: редактор (заглушка web-editor на TipTap + y-prosemirror со всей схемой контракта), значок, стиль (шрифт, ширина, бумага), подложка, бэклинки, история версий с откатом, присутствие других устройств и гостей.
- Задачи (Входящие / Сегодня / Скоро / Все / Выполненные) с контекстным меню из spec/12; календарь с лентой недели, задачами дня и ежедневной заметкой.
- Шеринг: диалог ссылки (просмотр/правка, срок, отзыв), гостевой маршрут без аккаунта с правкой.
- Настройки: аккаунт, блокноты и переключение режима с честным предупреждением, токены агентов и журнал, внешний вид.
- Мок-сервер (`apps/web/e2e/mock-server`) по контрактам — пока нет `apps/server`.
- Тесты: 15 unit (vitest), 7 e2e (Playwright: обложка на втором устройстве, регистрация и второе устройство, поиск, восстановление, задачи, офлайн с перезагрузкой, гость и отзыв ссылки). CI — `.github/workflows/web.yml`.

## Что решили (технически, в зоне потока)

- Мастер-ключ между перезагрузками хранится зашифрованным неизвлекаемым ключом WebCrypto в IndexedDB; обновления Yjs на устройстве лежат расшифрованными (устройство доверенное, как у Notesnook без «блокировки приложения»).
- Заглушки чужих пакетов подключаются через одну точку (`src/lib/shared.ts`, `src/ui`, `src/editor`).
- Аккаунт-документ дополнительно регистрируется `POST /v1/docs` (идемпотентно), если сервер не делает этого при регистрации.

## Вопросы координатору

1. История версий: сервер не может собрать состояние на `seq` из шифра. Предложение: версии = снимки, загруженные клиентами; веб дополнительно шлёт `snapshot` при уходе из документа после ≥ 30 правок. Нужно закрепить в контракте.
2. Перенос заметки между блокнотами: нет API смены блокнота документа (`PATCH /v1/docs/:id { notebookId }`) и переобёртки ключа заметки. Пока перенос — только внутри блокнота.
3. Регистрирует ли сервер `account`-документ при `signup`?
