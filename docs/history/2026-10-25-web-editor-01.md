# 2026-10-25 — поток web-editor, сессия 01

## Сделано

- Пакет `@datascratch/web-editor` с нуля: TipTap 3 + `y-prosemirror` над `Y.XmlFragment "content"`, схема строго по `document-model.md` (проверено тестом: имена узлов, атрибуты, метки, `link` только с `href`).
- `blockId`/`taskId` (UUIDv7): уникальность при разделении, вставке, дублировании.
- Неизвестные узлы/метки не теряются: заранее — отдельные типы с исходными именами; пришедшие на лету — защищённая схема + пересоздание редактора.
- Слой пера (D-05) на Canvas: ввод Pointer Events, привязка к символам через относительные позиции Yjs, перекладка, разрыв по строкам, D-35 с возвратом при отмене (в т. ч. удаление абзаца целиком), маркер под текстом, ластики, блок рисования, картинки, заметки на полях, hint, палитра.
- Меню «/», `[[`, панель форматирования, ручки блоков, меню задачи, курсоры соавторов, стиль и обложка документа.
- Лассо (выделение, перенос с перепривязкой, удаление) и жест «зигзаг — удалить».
- Перепривязка якорей после undo/redo (`rebaseRedoneAnchors`, временно у себя), подключены `@datascratch/ui` (правила дат, календарь) и токены.
- Витрина, 35 тестов vitest, 6 тестов Playwright CT, CI `web-editor.yml` — зелёный.

## Наблюдения для контрактов (отправлено координатору)

1. y-prosemirror записывает метку без атрибутов как `{}`, а не `true` (контракт §4.1). Читать нужно оба варианта.
2. `drawing.height` «в pt при ширине колонки 1.0»: на вебе высота масштабируется с шириной блока относительно опорной ширины 600 (как в формуле толщины). Нужна явная формула в контракте.
3. Заметки на полях (`anchorKind: "block"`) по смыслу лежат вне блока: `x` выходит за 0..1. Контракт пишет 0..1.
4. В тесте Yjs: относительная позиция удалённого символа резолвится не в null, а в соседнюю позицию — признак удаления клиент обязан проверять сам (по элементу Yjs с учётом redone). Стоит записать в `strokes.md` для iOS.
