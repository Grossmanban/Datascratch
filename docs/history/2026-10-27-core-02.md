# 2026-10-27 · поток core, сессия 02

Продолжение сессии `2026-10-25-core-01.md` (ветка `claude/core`), работа по поручениям координатора.

## Что сделано

- **Аудит безопасности** (f9a5f89b, 20f57621):
  - границы параметров KDF;
  - backoff после устойчивого соединения;
  - `rate_limited` с `retryAfterMs` без разрыва соединения;
  - очередь не теряет правки при сбое хранилища;
  - `subscribe` не больше 1000 документов, без повторов;
  - снимок до 16 MiB.
- **D-53, отключённое устройство** (187c408c):
  - коды согласованы с потоком server: 401 `device_revoked` с причиной; WS — кадр `error`, затем закрытие 4410;
  - `classifyApiFailure` отделяет отзыв устройства от истёкшего токена и сетевых сбоев;
  - событие `deviceRevoked(reason)` и статус `revoked` в `SyncClient`;
  - векторы `api/failures.json`; ios-core подключил их у себя.
- **D-54, совместный доступ по аккаунтам.**
  - Контракт этапа 1, согласован с server (102a74ec): `crypto.md` §10, раздел «Совместный доступ» в `api.md`, автор обновления и роль «только чтение» в `sync-protocol.md`, `account.shared` и версии ключей заметок в `document-model.md`; векторы `crypto/sharing.json`.
  - Клиент в `@datascratch/shared/sharing` (238abc2b): REST-клиент, пара ключей аккаунта, выдача ключей, смена ключа блокнота и заметки с продолжением после сбоя, пересоздание гостевых ссылок, «Общие со мной».
  - В `SyncClient`: `author`, `readOnly`, `keyMaybeStale`, `whenSent`.
  - `GET /shared-by-me` и `maintainOwnedShares` — один проход владельца при запуске (abad4925).

## Что решили

- Причины отзыва и код закрытия 4410 взяты из реализации server (координатор).
- Владелец продукта: гостевые ссылки после смены ключа пересоздаются; аккаунту, созданному после приглашения, ключ выдаётся только после подтверждения владельца.
- Координатор: `GET /shared-by-me`. При смене ключа новый ключ получают только участники `active`, а ждущие получают его позже, после подтверждения.
- Поток core: участник с правом «Может редактировать» кладёт заметки в корзину, но окончательно удалить заметку или вынести её из общего блокнота может только владелец.
