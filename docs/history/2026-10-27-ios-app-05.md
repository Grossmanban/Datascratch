# 2026-10-27 — ios-app, сборка 23 (D-54 + без DS_SERVER_URL)

Ветка `claude/ios-app-23` (main 3f2c5b55 + `claude/ios-core` cbaa72e4+).

## Сделано

- Ключи заметок по полному `NoteMeta` (версия + цепочка, D-54): `WrappedKeyIndex` хранит `keyVersion`/`keyChain`, `KeyRingDocumentKeys(keyRing:noteMeta:)`, `KeyRing.noteKey(_:notebookId:)`; перенос заметки сохраняет версию ключа (`wrappedKeyAD`); `healUnreadableNotes` не трогает заметки под прежним ключом общего блокнота.
- `DS_SERVER_URL` убран отовсюду вместе с миграцией сборки 22.
- `AccountSharingService` (`Services/AccountSharing.swift`): модели, локальная заглушка для UI-тестов (`-ui-testing-sharing`), серверная реализация (`Integration/ServerAccountSharing.swift`): приглашения, участники, «общие со мной» (`refreshSharedWithMe` → `CoreLibrary.setShared`), выдача ключей (`grantPendingKeys` с подтверждением владельца), смена ключа после удаления (`rotateNotebookKey`/`rotateNoteKey`, доделывание по `sharedByMe`), пересоздание гостевых ссылок (`ServerSharingService.recreateLinks`).
- Библиотека: общие блокноты — `Notebook.sharedSpaceId`, отдельно расшаренные заметки — виртуальный блокнот `Notebook.sharedNotesId` (нет документа блокнота; запись меты пропускается, тело пишется в документ заметки). В аккаунт пользователя общие блокноты не пишутся.
- UI: окно «Поделиться» (люди / приглашения / гостевые ссылки; у получателя — владелец, роль, «Выйти»), `InvitationsView`, раздел «Общие со мной», `SharingPrompts` (подтверждение владельца, «Ссылки обновлены»), «Только чтение» (полоса, без клавиатуры/пера/панелей, без правок в меню), меню блокнота для общих (только владелец переименовывает, переносит, удаляет и включает режим агентов), «Новая заметка» не создаёт в «только чтение».
- История версий: `NoteHistorySource` (сервер: `GET /docs/:id/versions` с авторами, расшифровка версии текущим или прежним ключом; без сервера — версии устройства), сравнение `TextDiff` (строки + слова), восстановление (`NoteDocument.restoreVersion`).
- Тесты: `SharingTests` (сравнение, роли, общие блокноты в библиотеке, версии ключей), UI `SharingUITests` (только чтение, приглашение по почте, принять приглашение).

## Открыто

- Настоящее «только чтение» в DSEditor (`EditorView.isReadOnly`) — запрос ios-editor через координатора; пока приложение скрывает инструменты и убирает клавиатуру.
- Курсоры соавторов с именами: на iOS нет присутствия вообще — предложено отдельной задачей.
- Значок ✨ у общих блокнотов получателя: режим блокнота владельца получателю неизвестен (нет поля в `shared-with-me`).
