# 2026-10-28 · ios-app · сессия 06 (сборка 24)

Ветка `claude/ios-app-24` от main.

## Сделано

- План сменился (D-56): вместо Universal Links своя схема `ds://` с адресом сервера в ссылке.
- `AppRoute` разбирает `ds://invite|share|note|notebook/<id>?server=<host[:port]>[#k=]` и своё `datascratch://`. Сервер в ссылке сравнивается с сервером аккаунта (`AppModel.linkServer`, с портом), иначе `otherServer` с веб-страницей той ссылки.
- Приглашение → `InvitationLinkView` (карточка, «Войдите», «уже не ждёт»). Гостевая → `SafariView` с гостевой страницей сервера из ссылки, аккаунт не нужен. Документ и блокнот → открыть или «здесь нет». Другой сервер → сообщение с «Открыть в браузере».
- Ссылка ждёт главного окна (`AppModel.pendingLink`) и разбирается против сервера на тот момент: холодный старт и ссылка до входа работают. Поле «Сервер» при входе и регистрации заполняется из ссылки (`serverFromLink`).
- Убраны `applinks:`, Associated Domains, `DS_WEB_HOST` (project.yml, Base.xcconfig, ios-release.yml, RELEASE.md, README). Заглушка адреса без сервера — `datascratch.invalid`.
- Тесты: разбор схем, серверов и портов, отказ от странных `server` (`RoutingTests`); UI — приглашение по ссылке при запуске, ссылка другого сервера (`-ui-testing-open-url`).
