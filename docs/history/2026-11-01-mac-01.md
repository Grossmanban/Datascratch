# 2026-11-01 — Mac-сессия 01

Первая сессия Claude Code на Mac владельца (Apple Silicon): сборка iOS, тесты на симуляторе, установка на iPad. Ветка `claude/mac`.

## Среда

- Xcode 26.5 (в CI — 26.6), Homebrew: `xcodegen`, `xcbeautify`, `pnpm`; Graphify и git-хук поставлены.
- Node.js: системная 22.9 слишком старая для `rolldown` (vitest не находит нативный модуль) — для проекта используется `node@22` (22.23) из Homebrew: `export PATH=/opt/homebrew/opt/node@22/bin:$PATH`.
- Тесты сервера — на отдельном временном PostgreSQL 16 (свой порт, `lc_messages = 'C'`: тест RLS ждёт английский текст ошибки).
- Симуляторы на Mac наследуют русский язык системы, а UI-тесты ждут английский, как в CI. Для тестов заведены отдельные симуляторы `DS-CI iPad` (iPad Pro 13" M5) и `DS-CI iPhone` (iPhone 17 Pro) с `en-US`.
- Подпись для устройства: платная команда владельца (Team ID в `Config/Local.xcconfig`, не в git). Debug-сборка установлена на iPad владельца (iPadOS 26.3.1) кабелем.

## Исправлено по отзыву (после выкладки)

- **Прыжок к началу заметки при «На весь экран»** (и Split View, поворот): редактор переносился в столбец другой ширины, UITextView сдвигал прокрутку на каждом шаге анимации. Редактор держит якорь чтения до конца изменения ширины.
- **Рассинхрон пера после смены ширины и стиля** (D-58): край рамки цеплялся к буквам заголовка над фразой. Теперь штрих, охватывающий строку, привязан только к ней (iOS и веб).
- Сворачивание приложения в симуляторе позицию не сбрасывает; если прыжок при переключении приложений повторится на устройстве — нужен точный сценарий (вероятна синхронизация при возвращении).
