## Сделано

- Модель: `Space.sharing` (`owned` / `joined`, nil — личное), `ShareTarget.Kind.space`; исчерпывающие `switch` дополнены.
- `CoreLibrary`:
  - документы пространств (`spaceDocument`, `adopt`);
  - в снимке — свои общие пространства (`Space.shared`) и пространства, куда приглашён (`account.sharedSpaces`, имя из документа пространства), их блокноты — из `SpaceDocument`;
  - запись: чужое пространство не пишется; переименование своего общего — и в документ пространства; блокноты общего пространства правятся в документе пространства, создаются и переносятся только через сервер;
  - `forgetSpace`: документы пропавшего пространства, его вкладки и избранное уходят.
- `AccountSharingService`: `makeShared(space:)`, `createNotebook(inSharedSpace:)`, `moveNotebook(_:toSpace:)`, роль по пространству (`role(forNotebook:)`, `spaceOfNotebook`). Сервер:
  - `shareSpace` (и при первом приглашении в личное пространство);
  - `createNotebook(name:in:)`, `moveNotebookIntoSpace` / `moveNotebookOutOfSpace`;
  - ключ пространства принявшим (`grantPendingKeys(.space)`), смена ключа при удалении (`rotateSpaceKey`), доделка при запуске (`resumeSpaceRotation` / `finishSpaceRotation`);
  - `refreshSharedSpaces` при обновлении, `placeSharedSpaces` у участника, «Выйти» из пространства.
- UI:
  - переключатель: разделы личных и общих, аватары участников, «Новое общее пространство…», «Пригласить в пространство…» / «Участники пространства…»;
  - `SpaceMembersSheet` (люди D-54 для пространства, «Выйти» у участника);
  - в «Поделиться» блокнота общего пространства — `SpaceAccessSection` вместо людей блокнота;
  - меню блокнота: перенос в общее пространство и обратно с предупреждением; «Участники пространства…» у участника;
  - редактор блокнота: в общем пространстве — создание через сервер;
  - читатель общего пространства: без «+» блокнота и без правки.
- Тесты: `SharingTests` (снимок пространства, куда приглашён; роль пространства на блокноты и заметки), UI `testJoinedSharedSpaceIsInTheSwitcher`, `testInvitingToAPersonalSpace` (заглушка `-ui-testing-sharing`: пространство «Team», роль «может редактировать»).
