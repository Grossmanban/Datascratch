# Открытые вопросы

> Не решать молча: каждый вопрос закрывается обсуждением с пользователем и оформляется ADR. Указано, к какому этапу вопрос нужно закрыть.

## Нужно до или во время этапа 1

- [ ] **Минимальная версия iOS/iPadOS.** Предложение: текущая и предыдущая мажорные версии. → при создании Xcode-проекта.
- [ ] **XcodeGen** для описания Xcode-проекта текстом (D-28, ПРЕДЛОЖЕНО).
- [ ] **Детали «живого штриха»:** обводки вокруг нескольких слов; стрелки между словами на разных строках. → на прототипе.
- [ ] **Штрих на удалённом тексте** (R-04): что происходит с пометкой, если помеченный текст удалён целиком или частично, в том числе одновременно на другом устройстве. Варианты: удалять вместе с текстом (с возможностью отмены), «прилипать» к ближайшему оставшемуся символу, переносить в «потерянные». → на прототипе.
- [ ] **Аккаунт Apple Developer** ($99/год). Без него приложение на iPad, поставленное из Xcode, работает 7 дней, потом его надо переустанавливать. Нужен для TestFlight, App Store, Universal Links. → когда переустановка начнёт мешать; точно — до этапа 3.

- [ ] **PDF-аннотации не в MVP** (D-08) — подтвердить.
