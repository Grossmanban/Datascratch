# 1. Концепция продукта

## Суть в одном абзаце

Приложение для заметок, где **рукописный ввод Apple Pencil и обычный текст живут в одном слое**: пером можно подчеркнуть, зачеркнуть, обвести или заштриховать любое слово прямо в тексте и рисовать прямо на картинках, и пометки едут вместе с текстом при любой перекладке. Это гибрид **Obsidian** (связи, бэклинки, теги, экспорт в Markdown) и **Notesnook** (сквозное шифрование, быстрая надёжная синхронизация), плюс **доступ для внешних ИИ-агентов** через API и MCP: агент извне читает заметки, ищет, вносит правки. Клиенты: нативные iPhone и iPad (главные, App Store) и полноценный веб вместо десктопа. Свой сервер.

## Почему не существующие приложения

Со слов пользователя:

- **Obsidian** не устраивает: всё лежит в файлах, это слишком нагружено для нормальной синхронизации через Apple.
- **Во всех приложениях с рукописью** текст и рукопись лежат на разных уровнях и не соприкасаются: нельзя по-настоящему подчеркнуть что-то в обычном тексте (не считая маркера), а при перекладке текста рукописные пометки остаются на месте, а не едут за словами.
- **Notesnook** хорош шифрованием и синхронизацией, но не даёт связей уровня Obsidian и не пускает внешних агентов.

## Главные принципы

1. **Перо в тексте — ключевая фича** и главный технический риск. Его качество важнее широты функций. См. `03-pencil.md`.
2. **Дизайн — основная концепция** (D-15): интерфейс уровня премиального SaaS, а не «программа энтузиаста». Компромиссы по красоте и плавности — только через обсуждение с пользователем. См. `05-organization-design.md`.
3. **Приватность по умолчанию, открытость по выбору**: приватные блокноты зашифрованы сквозным шифрованием, блокноты «для агентов» доступны внешним ИИ по токену (D-04, D-09). См. `07-encryption.md`.
4. **Агенты — снаружи**: встроенного ИИ нет (возможно в будущем), но любой внешний агент (Claude, ChatGPT и т. п.) может читать, искать и править заметки через MCP/REST. См. `09-agents-api.md`.
5. **Офлайн-первый**: всё работает без сети, сервер — для обмена. См. `10-sync.md`.

## Аудитория (D-12)

В первую очередь — для самого автора, позже, возможно, узкий круг. Не массовый продукт на старте. Монетизация не решена (D-18), но архитектура с первого дня готова к self-hosting (поднимается одной командой Docker).

## Связанные решения

D-01 (хранение в БД, не файлы), D-02 (нет десктопа, есть веб), D-03 (платформы), D-04 (шифрование + API), D-12 (аудитория), D-15 (дизайн), D-18 (монетизация), D-19 (код пишет Claude), D-20 (без дедлайна), D-24 (название).
