# 2. Платформы

Решения: D-02 (нет отдельного десктопа), D-03 (натив iOS + полный веб), D-06 (рисование пальцем на iPhone), D-17 (языки).

| Клиент | Роль | Ключевое |
| --- | --- | --- |
| iPad | Главный, работа с пером | Apple Pencil, Pencil Pro (сжатие, вращение), hover, Stage Manager, клавиатура и шорткаты |
| iPhone | Главный, быстрые заметки | Тот же код, что iPad; удобство одной рукой; рисование пальцем — опция в настройках (D-06) |
| Веб | Полноценная замена десктопа | Все функции, включая рукопись мышью и стилусом (Pointer Events с нажимом; Safari на iPad отдаёт нажим пера), офлайн, установка как PWA, удобная правка в мобильном браузере (для гостей по ссылке) |

## Требования

- На iOS редактор **только нативный**, не WebView — иначе заметна задержка пера.
- iPhone и iPad — **один код**, одно приложение (universal app).
- Веб — **без урезаний**: всё, что есть на iOS, есть в вебе (качество пера в вебе может быть ниже нативного — см. `risks.md`, R-07).
- Отдельной десктоп-версии нет (D-02), на компьютере — веб.
- Языки интерфейса: русский и английский. RTL не нужен (D-17).

## Минимальная версия iOS/iPadOS — ОТКРЫТО

Предложение: текущая и предыдущая мажорные версии. Точное число зафиксируем при создании Xcode-проекта на этапе 1 (по фактически актуальным на тот момент версиям). Возможности Pencil Pro (сжатие, вращение) требуют iPadOS 17.5+, так что любое разумное «текущая + предыдущая» их покрывает.

## Тестовые устройства (известно на 2026-10-25)

- Mac на Apple Silicon с Xcode — для сборки.
- iPad с **Apple Pencil Pro** — для проверки пера (доступны нажим, наклон, hover, сжатие, вращение).
