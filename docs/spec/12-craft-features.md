# 12. Функции по мотивам Craft

> Решение D-41. Включить функции — РЕШЕНО; разбивка по этапам — ПРЕДЛОЖЕНО (может быть пересмотрена пользователем). Перо в тексте (D-05) остаётся главной фичей: ни одна функция ниже не должна ухудшать его качество.

Ориентир — скриншоты Craft, присланные пользователем 2026-10-25 (описание — в D-38 и ниже).

## 12.1. Задачи

| Функция | Этап |
| --- | --- |
| Задачи (чек-боксы) прямо в любом документе — блок `taskItem` | MVP |
| У задачи: дата «запланировано», дедлайн, отметка выполнения/отмены | MVP |
| Отдельные задачи вне документов — во «Входящих» (`Inbox`, служебная заметка блокнота) | MVP |
| Единый экран «Задачи»: Входящие / Сегодня / Скоро / Все — собирает задачи из всех документов текущего пространства (D-48) | MVP |
| Контекстное меню задачи: перенести (Сегодня / Завтра / След. неделя / Дата…), дедлайн, выполнить, отменить, открыть документ, переместить, удалить | MVP |
| Напоминания (локальные уведомления iOS; в вебе — позже) | После MVP |

Задачи хранятся там, где их написали (в документе); экран «Задачи» — это локальный индекс, собранный из документов на устройстве (сервер содержимое не видит).

## 12.5. Коллекции

Коллекция — набор записей со свойствами (текст, число, дата, выбор, флажок, ссылка на документ) и видами **таблица / галерея / канбан** с фильтром, сортировкой и группировкой. — **После MVP.**

## 12.7. Обложка документа — РЕШЕНО (пользователь, 2026-10-25)

- Обложка — **только своё изображение**: фото из галереи, файл, скриншот, вставка из буфера. Готовых градиентов и цветных пятен нет.
- Шапка компактная (не больше ~⅕ высоты экрана телефона), со сдвигом кадра (`cover.offsetY`).
- Главный смысл — узнаваемость: миниатюра обложки показывается на карточке документа в сетке/списке (`NoteMeta.coverThumb`).
- По умолчанию обложки нет; добавляется через меню «…» → «Обложка».
- `meta.backdrop` (подложка-цвет/градиент) — не путать с обложкой; в интерфейсе не предлагается до отдельного решения.
