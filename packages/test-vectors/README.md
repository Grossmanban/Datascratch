# packages/test-vectors — общие тестовые векторы

Наборы «вход → ожидаемый выход» для шифрования, формата документа и штрихов, синхронизации. Прогоняются и в Swift (iOS), и в TypeScript (веб, сервер) — так гарантируется совместимость без общего ядра (D-22).

**Статус:** пусто. Первые векторы — формат штриха на этапе 1–2, шифрование на этапе 3.
